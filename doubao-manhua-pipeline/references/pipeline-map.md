# 全流程映射表（阶段执行时使用）

总控 Skill 串联四个独立子 Skill。执行某阶段前，必须先在技能根目录中定位并 Read 对应子 Skill 的 SKILL.md（可通过技能根目录检索 skill 名称找到），再按其标准流程执行。

## 子 Skill 清单

| 阶段 | 子 Skill 名称 | 功能 | 主要输入 | 主要产出 |
|---|---|---|---|---|
| ① 写小说 | doubao-original-novel | 自写小说·原创全流程 | 题材、字数、（可选）故事大纲 | 小说最终完整版全文 |
| ② 转剧本 | doubao-novel-to-script | 小说转剧本·漫剧改编 | 小说类型（题材）、小说原文 | 完整分场剧本 |
| ③ 转分镜 | doubao-script-to-storyboard | 剧本转分镜·即梦适配 | 剧本类型（题材）、剧本原文 | 完整分镜词（标准15秒版/豆包10秒版） |
| ④ 三视图 | doubao-three-view-prompt | 三视图提示词生成 | 小说类别（题材）、小说原文 | 人物/兵器/神兽/法宝/道具/场景全部三视图提示词 |

## 全流程数据链路

```
[题材+字数+大纲]
   │ ① doubao-original-novel
   ▼
小说全文 ──────► ③? 否
   │ ② doubao-novel-to-script
   ▼
完整剧本 ──────► ③ doubao-script-to-storyboard
   │                    │
   │                    ▼
   │              完整分镜词（含10秒版可选）
   ▼
（小说全文复用于④）
   │ ④ doubao-three-view-prompt
   ▼
全部三视图提示词
```

关键说明：
- 阶段④（三视图）从**小说原文**提取元素，非从剧本；全流程中复用阶段①产出的小说全文。
- 阶段③（转分镜）从**剧本**转化，使用阶段②产出。
- 每个阶段产出必须完整保留，作为后续阶段输入或最终交付物。

## 各阶段执行要点（速查）

### ① 写小说（doubao-original-novel）
- 确认题材、字数、大纲；无大纲由 AI 原创设计并说明。
- 8 阶段：原创策划 → 抖音叙事初稿 → 设定补全升级 → 合规核查 → 完整版 → 流量审核 → 最终完整版 → 流程固化。
- 强制门禁：原创规避（阶段0）、合规核查（阶段3）。

### ② 转剧本（doubao-novel-to-script）
- 确认题材；完整输出标准模板+类型特化规则；等待小说原文。
- 8 阶段：确认 → 输出模板+类型特化 → 等待原文 → 转化 → 对照原文审核 → 精简 → 连贯性审核 → 流程固化。
- 硬约束：剧情忠于原著、对话完整保留、先等原文。

### ③ 转分镜（doubao-script-to-storyboard）
- 确认题材与输出格式（15秒版/豆包10秒版）；完整输出标准模板+类型特化；等待剧本。
- 阶段：生成完整分镜词 → 审核修正 → 台词检查 → 特效 → 景别运镜 → 时间线重排 → 合规 → 即梦可生成性 → 输出完整分镜词。
- 硬约束：片段时长1-15秒（10秒版8-10秒）、镜头之和=片段时长、台词时限、特效仅限关键动作场景、台词字段纯净。

### ④ 三视图（doubao-three-view-prompt）
- 确认题材；生成题材特化模板（六板块约束不变）→ 模板审核 → 等待小说原文 → 元素提取生成三视图提示词 → 提取审核。
- 硬约束：人物净身/自然平静/鞋履合规、场景空无一人一兽、神兽法宝特效分级、忠于原文。

## 输入依赖提醒

全流程中每阶段可能有新的用户输入需求：
- 阶段①需题材/字数/大纲（可一轮确认）。
- 阶段②、④需小说原文（全流程中可直接复用阶段①产出，无需用户重复提供）。
- 阶段③需剧本（复用阶段②产出）。
- 若用户中途提供/修改原文，以用户最新提供为准，并重新执行受影响阶段。

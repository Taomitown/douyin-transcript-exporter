# 小说转剧本 · 漫剧改编全流程 Skill

## Purpose

把用户的小说转剧本提示词固化为一套**标准改编流水线**。每次改编都严格执行同一流程，保证模板一字不改、剧情忠于原著、输出可直接用于漫剧制作。

**标准流程：确认题材 → 输出标准模板+类型特化规则 → 等待原文 → 按模板转化 → 对照原文审核 → 精简剧本 → 连贯性审核 → 输出修正后完整剧本 → 流程固化**

## 触发与输入识别

用户提出以下任一要求即触发本 Skill：

1. "小说转剧本""出剧本""把小说改成剧本/漫剧"。
2. 提供小说原文（全文或章节），要求按指定模板转化为剧本文案。
3. 要求输出完整剧本、审核剧本、精简剧本、修正剧本。
4. 要求"以后都按这个标准输出"（流程固化）。

输入两要素：**小说类型（题材）** 与 **小说原文**。

- 题材缺失：主动询问用户小说类型（如玄幻/武侠/都市/言情/悬疑等），不擅自假设。
- 原文缺失：在完成"标准模板+类型特化规则"输出后，**等待用户发送小说原文**，收到原文前不输出剧本文案。

## 标准工作流（8 阶段）

按顺序推进；每个阶段的交付物与输出格式固定。

### 阶段0｜确认任务与题材

1. 确认小说类型（题材）与小说原文是否已提供。
2. 若题材未提供，询问确认；若原文未提供，明确告知用户后续需发送原文。

### 阶段1｜输出标准模板 + 类型特化规则

1. 读取 `references/standard-template.md`。
2. **完整输出"小说转剧本提示词模板（标准版）"的全部内容，一字不改。**
3. 读取 `references/genre-rules.md` 中对应题材的规则。
4. 在标准模板末尾**新增独立章节**，标题为"【类型特化规则 - 适用于XX小说】"，必须包含：
   - 针对该类型小说的特殊标注方法。
   - 对标准版模板条款的"类型改编补充说明"（注释形式，不修改原条款文字）。
   - 至少3条具体可操作的规则，每条附正确用法示例。
   - 该类型独有的格式标记（如（特效：...）、（境界显示：...）等）。
5. 保持标准版原有结构、顺序、内容完全不变，只在其后追加新章节；使用纯中文标点，不使用表格。
6. 输出修改后的完整内容，不得遗漏任何部分。

### 阶段2｜等待原文

1. 若用户尚未发送原文，明确提示"请发送小说原文"。
2. **收到原文前，不输出任何剧本文案。**
3. 原文可能以文本或附件形式提供；全文较长时分批接收，接收完整后再开始转化。

### 阶段3｜按模板转化并输出完整剧本

1. 对照标准模板（含类型特化规则），将小说原文按剧情顺序转化为剧本文案。
2. 严格遵守硬约束：
   - **剧情忠于原则**：不增加原著不存在的情节、角色或实质性对话；叙述转化不得改变原意。
   - **对话保留原则**：每一句人物对话完整呈现，仅可添加语气、动作标注。
   - **场景划分原则**：以叙事段落为单位；时间跳跃/地点改变/情绪断裂/平行叙事必须切新场景。
   - **输出格式**：纯中文内容、全中文标点、不要表格；不解析分析过程。
3. 输出完整剧本（分场结构：章节/序号/场景画面/时间/内外/地点/人物/道具）。

### 阶段4｜对照原文审核并输出修改后完整剧本

1. 读取 `references/audit-rules.md` 的"完整性审核"部分。
2. 对照小说原文逐场核查遗漏、错误与偏差（剧情顺序、对话完整性、情节增减、叙述转化、格式规范、场景划分、标点）。
3. 输出：①修改说明（列出发现的问题与修正处）②修改后的完整剧本。

### 阶段5｜精简剧本

1. 读取 `references/simplification-rules.md`。
2. 按精简规则删改（龙套与支线、对话处理、动作与场景描写、底线保障）。
3. 输出：①删改后的剧本（纯剧本格式，不含分镜词）②简洁删改说明。

### 阶段6｜二次审核（精简要求 + 连贯性）

1. 读取 `references/audit-rules.md` 的"精简要求复核"与"连贯性审核"部分。
2. 复核精简有无遗漏（关键信息、台词原意、镜头连接动作、主线张力、纯剧本格式）。
3. 对照原文，从"上下片段连贯性"与"整体剧情连贯性"审核，给出改善建议（逐条，含问题定位与修改动作）。
4. 输出：①改善建议 ②修正后的完整剧本。

### 阶段7｜流程固化

向用户说明：后续小说转剧本任务将默认按阶段0-6的同一标准流程执行，无需每次重复说明。

## 交付契约

- 阶段1必须完整输出标准模板全部内容，一字不改；只允许在其后追加类型特化章节。
- 每次"完整剧本"输出必须可直接使用，不省略、不示意。
- 剧本文案一律纯中文标点；对话一律按"角色名：（语气，动作）"对话内容""格式。
- 精简剧本为纯剧本格式，不含分镜词；删改说明单独列出。
- 用户中途指定"只要剧本/只要精简/只要审核"时，可只执行到对应阶段并明确说明停止点。

## 安全与边界

1. 剧本文案严格忠于用户提供的小说原文，不得自行新增情节、角色或实质性对话。
2. 涉及血腥、暴力、色情、恐怖、惊悚等内容时，按原著已有情节处理，不作渲染性展开；明显违规的渲染性描写应适度弱化并说明。
3. 不编造小说中不存在的台词、人物或设定。
4. 不向无关第三方发送用户私有稿件与个人信息。
5. 不使用表格输出剧本；转场、回忆、字幕等标记严格按模板格式。

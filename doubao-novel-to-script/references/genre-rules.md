# 类型特化规则库（阶段1使用）

用途：用户指定小说类型后，读取本文件对应题材的规则，在标准模板末尾新增独立章节"【类型特化规则 - 适用于XX小说】"。该章节必须包含：①针对该类型的特殊标注方法 ②对标准版条款的"类型改编补充说明"（注释形式，不修改原条款文字）③至少3条具体可操作的规则 + 正确用法示例 ④该类型独有的格式标记。

输出时保持标准版模板原有结构、顺序、内容完全不变，只在其后追加新章节；使用纯中文标点，不使用表格。

---

## 玄幻 / 仙侠

- 特殊标注方法：境界与突破需用特效与境界显示标注；法宝灵器需标注品级、来历、功能；天地异象单独标记。
- 类型改编补充说明：
  - （对"时长控制"）战斗场景按动作场景标准可延长至3分钟；突破、渡劫等大场面可单独成场景。
  - （对"道具"）法宝灵器统一纳入道具栏，标注（法宝：品级与功能），且突破类道具作用重大时标（关键）。
  - （对"转场"）跨境界、跨地图跳跃用 [切至] 并附（字幕：三年后）或（字幕：北境）。
- 规则示例：
  - （特效：丹田金光乍现，灵气如潮水涌入经脉）
  - （境界显示：炼气期七层）→ 沈烬：（低声，握紧灯芯）"终于……突破了吗。"
  - （特效：剑光如虹，劈开云海）
- 独有格式标记：（特效：...）、（境界显示：...）、（法宝：...）、（天地异象：...）、（灵力波动：...）

## 武侠

- 特殊标注方法：招式名称需配动作分解；内力运行可用音效与轻微特效；兵器对拼需兵刃特写。
- 类型改编补充说明：
  - （对"动作描写"）一招一式的攻防应拆成连续动作，用△推进，避免静止对白。
  - （对"无对话场景"）比武、追杀等打斗优先用默剧式动作 + 兵器音效，对话点到即止。
  - （对"道具"）成名兵器统一标注（兵器：名讳与来历），决胜兵刃标（关键）。
- 规则示例：
  - （招式：雁回九转）△沈烬侧身，刀锋贴着剑脊滑过。
  - （内力：真气灌注刀身，嗡鸣声渐起）(音效)刀鸣如龙吟。
  - （兵刃特写：刀身上一道旧裂痕）△他指尖抚过裂痕，眼神骤冷。
- 独有格式标记：（招式：...）、（内力：...）、（兵刃特写：...）、（轻功：...）

## 都市 / 现代

- 特殊标注方法：手机消息、屏幕界面、时间戳需标注；空间场景（办公室、车内、街道）节奏明快，切换迅速。
- 类型改编补充说明：
  - （对"转场标记"）现代快节奏叙事多用 [切至] 与 [划像]，并列场景（电话两端、两处地点同时发生）用 [划像]。
  - （对"道具"）手机、文件、监控画面等现代道具标注（屏幕特写：...）或（信息提示音）。
  - （对"节奏控制"）删减会议、寒暄类低信息场景，优先保留冲突与反转。
- 规则示例：
  - （信息提示音）△沈烬低头，屏幕亮起一行字：查到了，当年那场火。
  - （屏幕特写：转账记录，金额清晰可见）林深：（冷漠）"证据在你自己手里。"
  - （时间戳：凌晨3:47）(音效)城市空荡，只有车轮碾过积水的声音。
- 独有格式标记：（屏幕特写：...）、（信息提示音）、（时间戳：...）、（定位：...）

## 言情 / 古言

- 特殊标注方法：情绪外化强化——眼神、指尖、呼吸等微表情动作优先外化；心跳、呼吸等情绪音效；内心独白适度使用。
- 类型改编补充说明：
  - （对"内心独白"）言情可用内心独白表达未被说出口的情愫，但每场不超过1-2句，避免滥用。
  - （对"对话格式"）语气标注细化到"微微发颤""别开眼"等状态，让情绪可见。
  - （对"无对话场景"）靠近、错过、背影等情绪场景可用默剧式处理，配情绪音效。
- 规则示例：
  - （心跳声）△他抬手，指尖悬在她鬓边，又缓缓放下。
  - 沈烬：（低声，眼眶微红）"我以为……你不在了。"
  - （情绪特写：她攥紧袖口，指节泛白）林深：（温柔，别过眼）"我送你回去。"
- 独有格式标记：（情绪特写：...）、（心跳声）、（呼吸声）、（目光相接：...）

## 悬疑 / 推理

- 特殊标注方法：线索需显式埋设并标记；误导信息与疑点单列；闪回用于揭示信息差。
- 类型改编补充说明：
  - （对"道具"）案件相关物证统一标注（线索：...），首次出现标（关键）。
  - （对"回忆片段"）关键证词、案发经过用 [回忆片段开始 - 冷蓝色调] 呈现，区分现实与记忆。
  - （对"对话格式"）审讯、质询类对白保留完整逻辑链，不得合并或删减关键问答。
- 规则示例：
  - （线索：死者手心里攥着一枚染血的铜钱）△侦探拈起铜钱，眯起眼。
  - （疑点：监控里，那把伞在案发前一小时就停在门口）
  - [回忆片段开始 - 冷蓝色调]△凶手推开门的动作，与十年后如出一辙。[回忆片段结束]
- 独有格式标记：（线索：...）、（疑点：...）、（闪回：...）、（时间线：...）

## 科幻

- 特殊标注方法：科技装置需标注功能与状态；世界观设定（能源、规则、文明等级）用提示标注；全息界面、数据流可视化。
- 类型改编补充说明：
  - （对"道具"）高科技装备统一标注（科技：...），并注明能量/冷却状态。
  - （对"字幕"）世界观关键设定用（世界观提示：...）轻量点出，避免大段旁白。
  - （对"转场"）星际/维度跳跃用 [闪白] 或 [切至] 配特效标注。
- 规则示例：
  - （科技：量子通讯器，电量剩余12%）△通讯器红光闪烁，发出断续电流声。
  - （世界观提示：这座城市依赖地心熔炉供能，熄灭即沉没）
  - （全息界面：星图展开，标注出三处信号源）指挥官：（冷静）"分头追踪。"
- 独有格式标记：（科技：...）、（世界观提示：...）、（全息界面：...）、（能量状态：...）

## 恐怖 / 惊悚

- 特殊标注方法：惊吓点需显式标记；氛围以环境音、光影、呼吸推进；视觉惊吓与心理暗示并重。
- 类型改编补充说明：
  - （对"音效"）低语、脚步、门轴声等恐怖音效必须单独标注，是惊吓点的先导。
  - （对"无对话场景"）恐怖段落多用默剧式，主角台词极少，靠动作与声音制造压迫感。
  - （对"节奏控制"）惊吓点之间保留"喘息间隔"，避免连续惊吓导致疲劳。
- 规则示例：
  - （惊悚点：镜子里的人影比主角慢半拍转身）
  - (音效) 走廊尽头传来指甲刮过木板的声响。
  - （低语声）△沈烬猛地回头，身后空无一人，风却带着寒气。
- 独有格式标记：（惊悚点：...）、（低语声）、（心跳声）、（环境阴影：...）

## 末世 / 无限流

- 特殊标注方法：系统面板、倒计时、资源状态需可视化标注；副本/关卡切换独立场景。
- 类型改编补充说明：
  - （对"字幕"）副本进入、结算用（系统提示：...）或（字幕：第7天）。
  - （对"时长控制"）高燃战斗按动作场景标准，逃生、结算等情绪场景控制在1分钟内。
  - （对"转场"）副本之间用 [切至] 配（系统提示：新副本已开启）。
- 规则示例：
  - （系统提示：剩余时间 00:03:21）△倒计时数字在他瞳孔里跳动。
  - （资源栏：饮水 12%、弹药 8发）林深：（低喘）"撑到天亮就行。"
  - （怪物威胁：身后巷口传来密集脚步声）(音效)金属刮地声由远及近。
- 独有格式标记：（系统提示：...）、（剩余时间：...）、（资源栏：...）、（副本提示：...）

## 儿童文学 / 童话

- 特殊标注方法：语气词简化、动作分解清晰、节奏明快；用拟声词与色彩强化画面感。
- 类型改编补充说明：
  - （对"对话格式"）语气标注简单直白（高兴、害怕、好奇），避免复杂心理描写。
  - （对"动作描写"）动作分解为单步，一步一动，便于儿童理解。
  - （对"音效"）多用拟声词（叮咚、咕噜、哗啦）替代抽象环境描写。
- 规则示例：
  - 小兔子：（高兴，蹦跳起来）"找到啦！"
  - △小熊慢慢蹲下，轻轻敲了三下门。咚！咚！咚！
  - (音效) 咕噜咕噜——锅里冒出一串泡泡。
- 独有格式标记：（音效：轻快）、（动作分解：...）、（拟声词：...）

## 历史 / 权谋

- 特殊标注方法：朝堂、军阵、礼制等需标注空间结构；权谋对白保留逻辑与潜台词；用字幕标明年份与地点。
- 类型改编补充说明：
  - （对"字幕"）年代、战局用（字幕：景和三年，冬）标注，建立时空坐标。
  - （对"道具"）诏书、虎符、密信等权谋道具统一标（关键），特写承载信息量。
  - （对"对话格式"）君臣、密谈对白保留完整逻辑与弦外之音，不得删减转折句。
- 规则示例：
  - （字幕：景和三年，腊月，皇城）△殿前积雪，群臣屏息跪列。
  - （道具特写：虎符在烛光下反光）大将军：（低声）"兵权，可交，不可授。"
  - （音效）更漏滴答——殿内静得只剩呼吸。
- 独有格式标记：（字幕：...）、（道具特写：...）、（礼制：...）、（更漏声）

## 使用说明

1. 用户指定题材时，按对应题材生成特化章节；未覆盖题材时，参照上述结构自主编写。
2. 特化章节置于标准模板之后，标题格式固定为"【类型特化规则 - 适用于XX小说】"。
3. 补充说明一律以注释形式加在原条款下方，不修改原条款文字。
4. 规则示例必须具体、可直接套用，每条后附正确用法示例。

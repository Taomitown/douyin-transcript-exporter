# 剧本审核规则（阶段4、阶段6使用）

## 一、完整性审核（对照小说原文）

逐场对照原文核查，输出修改后的完整剧本：

1. 剧情顺序：是否严格按原著剧情顺序输出，无颠倒、无合并错位。
2. 对话完整性：小说中每一句人物对话是否完整呈现，无遗漏、无合并、无改写原意（仅允许添加语气、动作标注）。
3. 情节增减：是否增加了小说中不存在的情节、角色或实质性对话；是否遗漏了关键情节。
4. 叙述转化：心理描写、环境描写、动作描述的转化是否忠实原意，是否优先外化为动作、表情、环境音。
5. 格式规范：时间/内外/地点/人物/道具栏是否齐全；道具是否区分（关键）与（常规）并标注特写次数。
6. 场景划分：是否按叙事段落划分；时间跳跃、地点改变、情绪断裂、平行叙事是否按要求切新场景。
7. 标点符号：是否全部使用中文标点，无英文标点。

## 二、连贯性审核（上下片段 + 整体剧情）

从"上下片段连贯性"与"整体剧情连贯性"两个层面审核：

1. 上下片段连贯性：
   - 上一场结尾与下一场开头是否有因果或情绪承接。
   - 转场标记是否使用得当（[切至]/[淡出]/[叠化] 等）。
   - 人物进出是否会造成信息断层（读者能否看懂"谁在何时何地"）。
   - 时间线是否清晰（含（字幕：...）标注）。
2. 整体剧情连贯性：
   - 主线冲突是否完整贯穿所有场景。
   - 伏笔是否在后续得到回收或至少被提及。
   - 人物动机与行为是否前后一致。
   - 结尾是否与开头呼应、是否留出应有悬念。

## 三、精简要求复核（阶段6使用）

结合精简规则再次核对：

1. 是否遗漏承载关键信息的台词或动作。
2. 台词精简后是否仍保持原意、语气、潜台词。
3. 镜头连接性动作是否保留完整（避免后续分镜跳帧）。
4. 删改后主线是否完整连贯、戏剧张力是否保留。
5. 是否为纯剧本格式、不含分镜词。

## 四、审核输出格式

- 阶段4（对照原文审核）：先给出"修改说明"（列出发现的问题与修正处），再输出修改后的完整剧本。
- 阶段6（连贯性审核）：先给出"改善建议"（逐条说明，含问题定位与修改动作），再输出修正后的完整剧本。
- 结论不得超出检查范围；未发现问题的项也需明确说明已核查。

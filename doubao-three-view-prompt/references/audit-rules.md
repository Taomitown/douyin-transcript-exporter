# 模板审核规则（阶段2使用）

用途：对"适用于XX小说"的类型特化三视图模板进行逐板块审核，确保没有过度简化、约束减弱、擅自改动或遗漏。

## 一、人物板块审核

逐项对照标准模板核验：

1. **是否过度简化导致描述不够详细**：
   - 人物纯净约束（双手空置/腰间无悬挂/背负无行囊/仅性别固有配饰）是否完整保留？
   - 立体感与真实感硬约束（伦勃朗光+边缘光/次表面散射/法线贴图褶皱）是否完整？
   - 面容与皮肤细节规则（年龄分级/原文优先/五官精致度）是否完整？
   - 表情神态铁律（自然平静/原文神态覆盖三条件）是否完整？
   - 足部/长衫合拢/鞋袜分级/古风鞋履材质/翘头禁令/着袜分级/女性鞋履专项/瞳色/须发规则是否完整？
   - 正面全身/侧面全身/背面全身/正面头像特写四视图的字段细目是否完整（服饰/颜色/材质/纹饰/腰带/下摆/鞋履等）？
2. **是否约束力减弱**：任何"酌情""可省略""视情况"等弱化措辞，若标准版为绝对强制则必须恢复强制表述。
3. **是否擅自改动或遗漏**：与标准版逐条 diff，凡标准版存在而特化版缺失或改写的条款，一律补齐还原；仅允许删减"不属于该题材的时代分支"。

## 二、兵器 / 神兽妖兽动物 / 法宝 / 道具 / 场景五板块审核

按同一逻辑逐板块核对：

1. 兵器板块：双状态规则（有鞘→收纳+战斗两图；无鞘→仅战斗一图）、三视图完整收纳/本体约束、材质表面处理（冷兵器/现代/科幻）、部位细节是否完整。
2. 神兽妖兽动物板块：三视图完整全身约束、题材适配说明、神兽妖兽"特效分级+严禁普通动物化"、普通动物"无特效写实"是否完整。
3. 法宝板块：单状态三视图、题材分流说明、特效分级（仙家/魔道/元素）、半透材质与特效约束是否完整。
4. 道具板块：三视图、表面属性/纹饰/功能部件、现代物品息屏约束、无特效约束是否完整。
5. 场景板块：真实摄影风格、空无一人一兽、年代特征硬约束、时代分支（古风/玄幻/现代/科幻）是否与题材匹配且完整。
6. 各板块是否只删减了"不属于该题材"的内容，未误删本题材相关内容。

## 三、审核输出格式

按板块输出：
```
【板块X · 审核结论】通过 / 需修正
问题1（类型）：过度简化 / 约束减弱 / 擅自改动 / 遗漏
定位：<标准版对应条款>
修正：<补齐或还原的具体内容>
```
全部通过后，输出修正后的完整模板。

## 四、元素提取审核（阶段5，对照小说原文）

对生成的全部三视图提示词逐项核对：

1. **细节遗漏/差错**：每个元素提示词的年龄、身份、服饰、颜色、材质、纹饰、体征、武器法宝特效等是否与原文一致且完整；有无字段空缺、简写、含糊。
2. **元素遗漏**：对照小说原文逐章盘点，确认以下类别全部生成，无遗漏：
   - 人物（含配角、反派、关键角色）
   - 兵器/神器（含双状态）
   - 神兽/妖兽/普通动物
   - 法宝/灵宝/特殊器物
   - 道具（关键道具、反复出现道具）
   - 场景（主要场景、关键场景）
3. **格式一致**：每个元素的三视图提示词格式与新模板完全一致。
4. 输出：①遗漏/差错清单 ②修正后的全部三视图提示词。

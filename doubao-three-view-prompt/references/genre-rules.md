# 类型特化规则库（阶段1使用）

用途：用户指定小说类别后，基于标准模板（六板块细节要求/约束/生成规则全部保持不变）生成"适用于XX类别小说"的三视图提示词模板。要求：①重点突出该题材的典型风格与核心看点；②涵盖场景、人物、兵器、法宝、道具、动物神兽等关键元素的视觉呈现；③把不属于该类别的板块/条款去掉；④使用纯中文标点。

输出模板时：保留被命中的板块全部细节约束，删除被排除板块；被保留板块中与该题材无关的时代分支条款同步裁剪，只保留本题材对应的分支。

---

## 玄幻 / 仙侠

- 保留板块：人物（玄幻分支）、兵器（玄幻分支）、神兽/妖兽（玄幻神兽妖兽分支）、法宝/灵宝（仙家/魔道/元素分级）、道具、场景（玄幻分支）。
- 删除内容：现代类、科幻类、纯古风历史向的分支与条款；场景的"纯古风/现代/科幻"分支仅保留玄幻分支。
- 题材突出点：境界体系、法宝灵宝、神兽妖兽、天地异象、宗门秘境。核心看点是"超凡视觉"——灵气、符文、神光、异兽威压。
- 各板块重点：
  - 人物：允许灵气纤维布料、灵光发簪等超现实材质；神兽坐骑类角色按神兽板块。
  - 兵器：允许剑身灵气流转、符文发光；有鞘兵器双状态。
  - 神兽/妖兽：必须按"仙气类/魔气类/元素类"特效分级，严禁普通动物化。
  - 法宝/灵宝：必须携带符合品阶的高级特效（仙家灵宝/魔道邪宝/元素灵宝分级）。
  - 场景：允许悬浮山、护山大阵光膜、符文石柱、灵气缭绕。
- 无对应内容可删除的：纯古风鞋履"翘头禁令"等古风规则仍保留（玄幻人物着古装）。

## 武侠

- 保留板块：人物（古风分支）、兵器（冷兵器分支）、道具、场景（古风分支）、普通动物（如有坐骑/猎犬）。
- 删除内容：神兽/妖兽板块（武侠无神兽妖兽，仅保留"普通动物"子类型）；法宝/灵宝板块（如原文有特殊古物，改用道具板块）；现代/科幻分支与条款。
- 题材突出点：刀光剑影、门派恩怨、江湖气。核心看点是"写实冷兵器+江湖质感"。
- 各板块重点：
  - 人物：古风服饰合拢、布鞋布靴、侠客风霜面容；佩剑等装备不进入人物视图，单独生成兵器视图。
  - 兵器：冷兵器双状态（有鞘/无鞘）；岁月感包浆、云雷纹。
  - 道具：暗器、信物、酒葫芦、令牌等按道具板块。
  - 场景：纯古风分支，江湖质感（客栈、山门、竹林、城墙）。
- 无对应内容可删除的：古风全部硬约束（合拢穿着/鞋履材质/翘头禁令/着袜分级）保留。

## 古言 / 历史

- 保留板块：人物（古风分支）、道具（古物）、场景（纯古风分支）、普通动物（如有）。
- 删除内容：神兽/妖兽板块（仅保留"普通动物"子类型，纯古风不应出现神兽妖兽）；法宝/灵宝板块（特殊古物改用道具板块）；兵器板块仅当原文有兵器才保留；现代/科幻全部分支。
- 题材突出点：朝代审美、礼制、华服。核心看点是"历史真实感+古典华美"。
- 各板块重点：
  - 人物：官服/华服/布衣严格按身份匹配鞋履与洁净度；禁发光材质；翘头禁令；女性绣鞋平底。
  - 道具：古物（玉器、铜器、木器、瓷器），有岁月感包浆。
  - 场景：纯古风分支，庄重对称、飞檐斗拱、礼制布局。
- 特效边界：场景禁用发光/悬浮/灵气；人物禁用发光材质。

## 都市 / 现代

- 保留板块：人物（现代分支）、道具（现代物品分支）、场景（现代分支）、兵器（现代枪械分支，仅当原文有）。
- 删除内容：神兽/妖兽板块（现代写实题材无神兽妖兽）；法宝/灵宝板块（异能物品若原文有则按法宝板块"异能物品"类型）；古风全部分支与条款（合拢穿着/古风鞋履/翘头禁令/着袜分级/须发规则不适用）。
- 题材突出点：都市质感、时尚造型、现代生活场景。核心看点是"现代写实+时尚感"。
- 各板块重点：
  - 人物：现代服饰、皮鞋/运动鞋/帆布鞋按职业匹配洁净度；男性现代角色无古风须发规则。
  - 道具：手机、合同、行李箱等现代物品，屏幕息屏状态。
  - 场景：现代分支（客厅、咖啡厅、办公室、城市天际线），崭新洁净。
- 特效边界：写实题材无发光特效；异能设定除外。

## 科幻

- 保留板块：人物（科幻分支）、兵器（科幻能量武器分支）、场景（科幻分支）、道具（高科技装置分支）、神兽/妖兽（仅幻想生物——基因改造兽/机械兽/外星生物分支）。
- 删除内容：法宝/灵宝板块（高科技装置按法宝板块"高科技装置/异能物品"类型或道具板块处理，视超凡与否）；古风全部分支与条款。
- 题材突出点：未来主义、科技奇观、冷冽光效。核心看点是"精密科技感+未来美学"。
- 各板块重点：
  - 人物：科技面料、功能束带、脊柱外骨骼、发光脊线；鞋履战术靴/机甲靴。
  - 兵器：能量武器激活形态、全息界面。
  - 神兽/妖兽：机械兽/外星生物用生物荧光、电弧、纳米雾特效。
  - 场景：科幻分支（太空舱、实验室、未来都市），冷白冰蓝银灰主调。
- 特效边界：所有特效须符合真实物理光学，禁赛博朋克插画感。

## 悬疑 / 推理

- 保留板块：按题材设定——若为现代悬疑按"都市/现代"规则；若为民国/古风悬疑按对应时代规则。
- 删除内容：神兽/妖兽板块（写实悬疑无）；法宝/灵宝板块（除非异能设定）。
- 题材突出点：氛围感、细节线索、压抑或冷峻色调。核心看点是"氛围张力+细节真实"。
- 各板块重点：
  - 人物：按时代分支，气质多沉静、警惕；场景光影偏暗调或冷调。
  - 道具：案件物证（信件、凶器、证物、日记）用道具板块，可带做旧痕迹。
  - 场景：按时代分支（雨夜街道、老宅、办公室、审讯室）。
- 特效边界：写实悬疑无特效；如含灵异/异能元素按对应分支。

## 末世 / 无限流

- 保留板块：人物（现代/科幻分支按设定）、场景（现代或科幻分支）、兵器（现代枪械或科幻能量武器）、道具（现代或科幻物品）、神兽/妖兽（变异兽/异兽分支）。
- 删除内容：法宝/灵宝板块（异能物品按需）；古风分支。
- 题材突出点：废土、变异、生存压迫。核心看点是"末世氛围+变异兽威压"。
- 各板块重点：
  - 人物：作战服/废土风，可带战斗痕迹（但人物纯净约束仍禁悬挂物，装备单独出图）。
  - 神兽/妖兽：变异兽用生物荧光、腐蚀雾、能量护盾视觉。
  - 场景：废土城市、避难所、废墟，现代/科幻分支。
- 特效边界：变异兽特效遵循"物理体积、动态衰减、与生物结构交互"。

## 儿童文学 / 童话

- 保留板块：人物、道具、场景、普通动物；魔法类可保留法宝（简化）与神兽（简化）。
- 删除内容：血腥、威压、复杂特效；写实厚重质感描述可适度柔化。
- 题材突出点：明快、可爱、色彩鲜艳。核心看点是"童趣+清晰可爱"。
- 各板块重点：
  - 人物：圆润可爱的国漫风格，但保持三维立体与皮肤质感。
  - 神兽/妖兽（如有）：简化为可爱吉祥型，特效轻量（星点、柔光）。
  - 场景：明快色彩、童话质感。
- 特效边界：轻量柔光，避免暗黑/恐怖元素。

---

## 使用说明

1. 用户指定题材时，按对应题材生成"适用于XX小说"的三视图提示词模板；未覆盖题材参照上述结构。
2. 被保留板块的细节要求、约束、生成规则一字不改；只删减不属于本题材的板块/时代分支。
3. 每板块保留其题材对应的时代分支示例与质感词，删除其余分支。
4. 类型特化模板输出后，必须进入"模板审核"阶段（见 audit-rules.md）。

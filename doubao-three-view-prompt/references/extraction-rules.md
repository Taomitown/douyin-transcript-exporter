# 元素提取规则（阶段4使用）

用途：收到小说原文后，严格按照新生成的三视图提示词模板，从原文提取所有元素，为每个元素生成对应的三视图提示词，格式与新模板完全一致。

## 一、提取流程

1. 通读小说原文（可分批），按章节与出现顺序盘点所有需要出图的元素。
2. 按六大板块分类登记：人物、兵器/神器、神兽/妖兽/普通动物、法宝/灵宝/特殊器物、道具、场景。
3. 逐元素从原文提取设定信息，填入对应板块模板。
4. 每个元素独立成一条三视图提示词，格式与新模板完全一致。

## 二、板块判定

- 人物：所有有明确形象/身份/台词/戏份的角色（含主角、配角、反派、关键路人）。只在剧中一闪而过的纯背景角色可不单独出图，但需在交付说明中列出。
- 兵器/神器：原文明确出现的武器。有鞘/匣/套的生成两张图（收纳+战斗）；无鞘的仅战斗一张。
- 神兽/妖兽/普通动物：原文出现的兽类；按"神兽/妖兽/普通动物"三选一判定；纯古风历史向只能选"普通动物"。
- 法宝/灵宝/特殊器物：具有超凡属性的器物；普通器物归入"道具"板块，不强制加特效。
- 道具：普通物品/非法宝类特殊道具，对剧情有作用的器物。
- 场景：主要/关键场景（人物驻留、剧情发生地、标志性地标）。

## 三、信息提取要求

1. **忠于原文**：年龄、性别、身份、服饰、颜色、材质、纹饰、体征（痣/疤/胎记）、瞳色、发式、须髯、携带装备、特效属性等严格按原文。
2. **未描写的默认处理**：原文未明确处，按人物年龄分级、身份对应的时代服饰/鞋履/洁净度默认规则补全，并在提示词中自然呈现，不做额外说明。
3. **人物纯净约束**：即使原文写明角色携带装备，人物视图一律"净身"呈现；该装备作为独立兵器/道具视图单独生成。
4. **表情神态**：人物基础视图只用"自然平静"默认态；原文属"剧情瞬间"的神态（冷笑、落泪等）不代入。
5. **鞋履/材质/纹饰/须发**：严格遵守人物板块的时代硬约束（合拢穿着、布履、翘头禁令、着袜分级、女性绣鞋平底、胡须中式样式等）。
6. **特效**：神兽/法宝等仅当原文赋予超凡属性时才加对应特效分级；普通动物/普通道具不加特效。

## 四、输出格式

按板块分组输出全部三视图提示词，每条格式与新模板完全一致：

```
【板块】人物 / 兵器 / 神兽妖兽动物 / 法宝 / 道具 / 场景
【名称】XXX
[对应板块模板全部字段，逐项填写完整]
```

输出顺序建议：人物 → 兵器 → 神兽妖兽动物 → 法宝 → 道具 → 场景，并按原文出场顺序排列。

## 五、交付前自查

- [ ] 每条提示词字段完整、无简写、无"同上"。
- [ ] 与原文设定一致，无杜撰。
- [ ] 人物视图净身、神态自然平静、鞋履合规。
- [ ] 神兽/法宝特效分级正确。
- [ ] 场景为空无一人一兽。
- [ ] 所有元素均已提取，无遗漏。

# 三视图提示词生成 · 全流程 Skill

## Purpose

把用户的三视图提示词标准模板（人物/兵器/神兽妖兽动物/法宝/道具/场景六板块）及其全流程固化为一套**标准出图提示词流水线**，用于小说/漫剧的角色、装备、兽类、器物与场景设定图生成。

**标准流程：确认任务 → 生成题材特化模板 → 模板审核（人物+五板块）→ 输出修正后完整模板 → 等待小说原文 → 元素提取生成三视图提示词 → 提取审核 → 流程固化**

## 触发与输入识别

用户提出以下任一要求即触发本 Skill：

1. "生成三视图""出三视图提示词""角色/兵器/神兽/法宝/道具/场景设定图提示词"。
2. 要求"基于标准模板生成适用于XX类别小说的三视图提示词模板"。
3. 提供小说原文，要求按模板提取所有元素并生成三视图提示词。
4. 要求审核模板（人物板块/其他板块）、审核已生成的三视图提示词是否有遗漏差错。
5. 要求"以后都按这个逻辑流程标准输出"（流程固化）。

输入两要素：**小说类别（题材）** 与 **小说原文**。

- 类别缺失：询问用户题材（玄幻/武侠/古言/都市/科幻/悬疑/末世/儿童等）。
- 原文缺失：在输出"题材特化模板"并审核通过后，**等待用户发送小说原文**，收到前不生成任何三视图提示词。

## 标准工作流（阶段化）

### 阶段0｜确认任务

1. 确认小说类别（题材）与小说原文是否已提供。
2. 确认输出范围：仅模板 / 模板+元素提取。

### 阶段1｜生成题材特化三视图模板

1. 读取 `references/standard-template.md`（六板块标准模板）与 `references/genre-rules.md`（对应题材）。
2. 生成"适用于XX小说"的三视图提示词模板：
   - 人物、兵器、神兽妖兽动物、法宝、道具、场景六个板块的**细节要求、约束、生成规则全部保持不变**。
   - 重点突出该题材的典型风格与核心看点。
   - 覆盖场景、人物、兵器、法宝、道具、动物神兽等关键元素的视觉呈现。
   - 把不属于该类别的板块/时代分支相关提示词去掉。
3. 若用户未指定类别，直接输出标准模板全文。

### 阶段2｜模板审核（人物板块 + 其他五板块）

1. 读取 `references/audit-rules.md` 的"模板审核"部分。
2. 先审核**人物板块**：是否有过度简化导致描述不够详细、约束力减弱、擅自改动或遗漏。
3. 再审核**兵器/神兽妖兽动物/法宝/道具/场景五板块**：同类型问题逐一排查。
4. 输出修正后的完整模板。

### 阶段3｜等待小说原文

1. 明确提示"请发送小说原文"。
2. **收到原文前不输出任何三视图提示词。**
3. 原文较长时分批接收完整后再提取。

### 阶段4｜元素提取与三视图提示词生成

1. 读取 `references/extraction-rules.md`。
2. 严格按照新生成的模板，从小说原文提取所有元素。
3. 所有元素的三视图提示词格式与新模板完全一致（人物四视图/兵器双状态/神兽三视图/法宝三视图/道具三视图/场景单视图）。
4. 输出全部三视图提示词。

### 阶段5｜提取审核

1. 读取 `references/audit-rules.md` 的"元素提取审核"部分。
2. 对照新模板审核所有三视图提示词的细节是否有遗漏或差错。
3. 核对人物、道具、神兽动物、武器、场景、法宝等是否有遗漏生成。
4. 输出：①遗漏/差错清单 ②修正后的全部三视图提示词。

### 阶段6｜流程固化

向用户说明：后续三视图提示词生成任务默认按阶段0-5的同一流程执行，无需每次重复说明。

## 交付契约

- 题材特化模板中，被保留板块的细节要求/约束/生成规则一字不改；只删减不属于该类别的板块/时代分支。
- 每次"三视图提示词"输出必须字段完整、忠于原文、格式与新模板一致，无简写。
- 人物视图强制"净身+自然平静神态+鞋履合规"；神兽/法宝仅在原文赋予超凡属性时加特效分级。
- 场景视图空无一人一兽、年代特征严格匹配。
- 用户中途指定"只要模板/只要审核/只要提取"时，可只执行到对应阶段并说明停止点。

## 安全与边界

1. 三视图提示词严格忠于用户小说原文，不新增角色、装备、场景或设定。
2. 涉及血腥、暴力、色情等原文描写按合规要求弱化或规避呈现，不渲染细节。
3. 神兽/法宝特效分级遵循"物理体积、动态衰减、与结构交互"，避免无法生成。
4. 不编造原文不存在的元素；未描写细节按默认规则补全并自然呈现。
5. 不向无关第三方发送用户私有稿件与个人信息。

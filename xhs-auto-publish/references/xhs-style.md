# 小红书内容规范（图文 / 视频 / 动态）

小红书是「种草 + 真实感」平台。改写热点时把「新闻事实」转成「用户可用的干货」，保留原创、克制广告味。

## 通用要求

- **原创**：用自己的话重构，不照搬他人文案/图文；引用数据注明来源口径。
- **真实**：不编造体验、数据、收益；不确定的写「据官方/报道」。
- **合规**：不用「最/第一/100%」等绝对化用语；不医疗化；不站外导流（不放微信号/链接）；不诱导点赞收藏交易。

## 标题（≤20 字）

爆款公式（套 1~2 个即可）：
- 数字清单：「3 个免费提效工具，最后一个太香」
- 悬念/好奇：「手机里这 5 个设置，你大概率没关」
- 痛点+解法：「WiFi 总卡？问题出在这 3 处」
- 身份代入：「打工人必备的 4 个效率技巧」
- 对比反差：「同样做笔记，为什么 TA 效率翻倍」

规则：≤20 字；可带 1 个 emoji；不用「震惊体」过度夸张。

## 正文结构

1. **钩子（3 行内）**：一句话点出主题 + 用户能得到什么。
2. **干货主体**：分 3~5 段，每段一个小标题或要点；适度 emoji（每段 0~2 个）；多用换行分段，别写长段。
3. **互动结尾**：引导收藏/评论/关注（如「收藏不迷路」「你觉得哪个最实用？」）。

## 话题标签（topics）

- 3~8 个，首个放主领域标签（如 `#科技`、`#生活`）。
- 组合：领域 + 细分 + 场景（如 `#AI工具 #效率神器 #数码好物`）。
- 不用过长、不用空格分隔符。

## 封面规范（图文）

- 竖版 **3:4（1080×1440）**；主体清晰，标题大字（≤20 字），配色干净（背景 + 主色不超过 2~3 种）。
- 封面要点：主标题（卖点）+ 副标题（辅助信息）；人物/产品居中；避免密集小字。
- 生成方式：优先用图片生成能力按 `cover_prompt` 生成；或 `scripts/make_cover.py` 生成文字封面。

## 图文 / 视频 / 动态差异

| 形态 | type | 要求 |
|------|------|------|
| 图文 | `image` | 封面 + 2~5 张配图（信息图/实拍/截图均可），图与正文对应 |
| 视频 | `video` | 15~60s，竖版 9:16，前 3 秒钩子；需视频文件 + 封面帧 |
| 动态 | `dynamic` | 短正文（100 字内）可直接表达，可带 1 图，不需复杂封面 |

## 领域调性（默认科技 / 生活）

- **科技**：前沿动态、AI/数码/效率工具、实操教程、参数对比、避坑提醒。语气：专业但易懂，少黑话。
- **生活**：实用技巧、经验分享、省钱/好物、避坑指南。语气：亲切、具体、可落地。

改写示例（科技向，示意）：
> 热点：「某大模型发布新版本，支持长文本」
> 标题：「新模型上线，3 个普通人也能用到的场景」
> 正文钩子：「这两天新模型发布，别只看热闹——这几个场景我实测真的有用👇」

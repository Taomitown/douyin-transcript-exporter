# Doubao 漫剧制作技能集

一套面向 **抖音漫剧工业化生产** 的豆包工作台技能（Skill）集，覆盖从写小说到出图提示词的完整链路，支持 **一条龙全流程** 与 **单阶段独立使用** 两种模式。

> 核心流水线：**自写小说 → 小说转剧本 → 剧本转分镜 → 三视图提示词**，并配套全流程总控与一键推送工具。

---

## 技能总览

| Skill | 功能定位 | 典型触发 |
|---|---|---|
| `doubao-manhua-pipeline` | 全流程总控：路由并串联四个阶段 | "做一部漫剧一条龙" |
| `doubao-original-novel` | 自写小说·原创全流程（抖音叙事逻辑） | "写一部XX题材自写小说" |
| `doubao-novel-to-script` | 小说转剧本·漫剧改编全流程 | "把小说转成剧本" |
| `doubao-script-to-storyboard` | 剧本转分镜·即梦/Seedance 适配 | "剧本生成分镜词" |
| `doubao-three-view-prompt` | 三视图提示词（人物/兵器/神兽/法宝/道具/场景） | "生成三视图提示词" |
| `doubao-skill-push` | 技能仓库一键提交与推送 | "推一下技能" |
| `douyin-transcript-exporter` | 抖音博主视频数据与逐字稿采集 | "导出抖音逐字稿" |

## 各技能详细介绍

### 1. doubao-manhua-pipeline · 全流程总控

- **用途**：把四个子 Skill 串成一条可选的完整流水线，负责"路由与排序"，不重复实现子 Skill 细节。
- **模式**：
  - 一条龙全流程：`写小说 → 转剧本 → 转分镜 → 三视图` 自动推进，每阶段产出作为下阶段输入。
  - 组合流程：只要其中 2-3 步，按序执行。
  - 单阶段路由：只明确要一步时，直接转给对应子 Skill，总控不介入。
- **数据链路**：

```
[题材 + 字数 + 大纲]
   → doubao-original-novel        （写小说）→ 小说全文
   → doubao-novel-to-script       （转剧本）→ 完整剧本
   → doubao-script-to-storyboard  （转分镜）→ 完整分镜词（含豆包10秒版）
   → doubao-three-view-prompt     （三视图，复用小说原文）→ 全部三视图提示词
```

- **关键产出**：小说全文、完整剧本、完整分镜词、全部三视图提示词。

### 2. doubao-original-novel · 自写小说

- **用途**：按"抖音漫剧热门叙事逻辑 + 多重反转 + 高频爽点 + 段末留客钩子"的固定流水线生成原创小说。
- **8 阶段流程**：
  1. 需求确认与原创策划（原创版权规避）
  2. 抖音漫剧叙事初稿（强冲突开篇 / 密集反转 / 高频爽点 / 留客钩子）
  3. 全方位细节优化升级（人物支线 / 场景 / 异兽 / 道具 / 武器法宝全套设定）
  4. 合规核查与整改（血腥 / 暴力 / 色情 / 恐怖 / 惊悚排查）
  5. 输出修改后完整版
  6. 抖音流量爆点审核（逐条优化建议）
  7. 输出最终完整版
  8. 流程固化
- **硬约束**：原创版权规避、内容合规核查为强制门禁，不可跳过。
- **参考文档**：`references/`（原创规避 / 抖音叙事 / 世界观设定 / 合规规范）。

### 3. doubao-novel-to-script · 小说转剧本

- **用途**：把小说按"漫剧剧本标准"改编为分场剧本，类型特化强化看点爆点。
- **8 阶段流程**：
  1. 完整输出标准版模板（一字不改）
  2. 追加"类型特化规则"（针对指定小说类型）
  3. 等待小说原文（收到前不输出）
  4. 严格按模板转化剧本
  5. 对照原文审核（有无遗漏 / 错误）
  6. 输出修改后完整剧本
  7. 精简剧本（龙套 / 支线 / 对话压缩，保精彩度）
  8. 连贯性审核 + 流程固化
- **硬约束**：剧情忠于原著、每句对话完整保留、先等原文再输出。
- **参考文档**：`references/`（标准模板 / 类型特化 / 精简规则 / 审核规则）。

### 4. doubao-script-to-storyboard · 剧本转分镜

- **用途**：把剧本转化为即梦/Seedance 2.0 可直接生成视频的分镜词。
- **核心能力**：
  - 片段时长 1-15 秒强制规则，镜头时长之和精确等于片段时长。
  - 台词-画面时长协调（语速基准 / 超长拆分 / 跨片段连续性）。
  - 旁白转内心独白、切割点、占位一致性（即梦无记忆）。
  - 15 项输出校验清单（道具连续性 / 空间景深 / 台词字段纯净度等）。
  - 支持"标准 15 秒版"与"豆包 10 秒版（8-10 秒 / 每段≤2 镜头）"。
  - 特效仅限打斗 / 神兽 / 大功初成 / 法宝等关键动作场景，层次适度不过于复杂。
- **硬约束**：台词字段格式禁令、合规审核、即梦可生成性审核。
- **参考文档**：`references/`（标准模板 / 类型特化 / 优化规则 / 审核规则 / 豆包10秒适配）。

### 5. doubao-three-view-prompt · 三视图提示词

- **用途**：为小说/漫剧生成角色、装备、兽类、器物与场景的设定图三视图/四视图提示词。
- **六大板块**：人物（四视图合并）· 兵器（双状态）· 神兽/妖兽/动物（三视图）· 法宝/灵宝（三视图）· 道具（三视图）· 场景（单视图）。
- **关键规则**：
  - 人物：净身约束（绝对最高优先级）、年龄分级皮肤、定妆照铁律、古风合拢穿着 / 鞋履材质 / 翘头禁令 / 着袜分级 / 女性绣鞋专项 / 中式须发。
  - 兵器：有鞘→收纳+战斗双图；无鞘→仅战斗图。
  - 神兽/法宝：特效分级（仙气 / 魔气 / 元素），严禁普通化。
  - 场景：真实摄影风格、空无一人一兽、年代特征硬约束（古风/玄幻/现代/科幻）。
- **流程**：生成题材特化模板 → 模板审核（人物+五板块）→ 等待原文 → 元素提取 → 提取审核。
- **参考文档**：`references/`（标准模板 / 类型特化 / 审核规则 / 元素提取规则）。

### 6. doubao-skill-push · 一键推送

- **用途**：技能仓库一键提交并推送到 GitHub，内置敏感信息拦截。
- **流程**：检查状态 → 敏感检查门禁 → 提交 → 推送 → 核验一致 → 报告。
- **快捷命令**：终端安装 `skill-push`（`~/.local/bin`），用法：`skill-push "提交说明"`。
- **参考**：`scripts/skill-push`（与终端命令逻辑一致）。

### 7. douyin-transcript-exporter · 抖音数据采集

- **用途**：抓取抖音博主主页或视频的标题、文案、完整逐字稿及互动数据。
- **输出**：可选写入飞书多维表格，或保存为本地文件。
- **参考文档**：`references/`（抖音采集 / 飞书写入）。

## 使用说明

- **安装**：把技能目录放入豆包工作台的 `user_skills` 技能根目录即可被识别。
- **触发**：对豆包直接说对应触发词（见总览表）；全流程可对总控 Skill 说"做一部漫剧一条龙"。
- **独立使用**：每个 Skill 独立可装、独立可用，互不依赖。
- **一键推送**：改动后终端执行 `skill-push`，或对豆包说"推一下技能"。

## 硬约束（全流程生效）

1. **原创版权规避**：不沿用已发表作品的独创表达，只借鉴公共题材套路。
2. **剧情忠于原著**：转剧本 / 转分镜 / 提取元素均忠于原文，不增删。
3. **合规核查**：血腥 / 暴力 / 色情 / 恐怖 / 惊悚内容先整改再交付。
4. **先等输入再输出**：剧本 / 分镜 / 三视图均需先收到原文才执行。

# 自写小说 · 原创全流程创作 Skill

## Purpose

把用户的自写小说提示词固化为一套**标准创作流水线**。每次生成都严格执行同一逻辑流程：

**原创策划 → 抖音叙事初稿 → 设定补全升级 → 合规核查 → 完整版输出 → 流量爆点审核 → 最终完整版输出 → 流程固化**

创作优先，但不放松两项硬约束：**版权原创规避**（阶段 0）与**内容合规**（阶段 3）是强制门禁，不可跳过。

## 触发与输入识别

用户提出以下任一要求即触发本 Skill：

1. 写"自写小说 / 原创小说 / 独立原创作品"，题材可为玄幻、仙侠、都市、末世、悬疑、无限流、古言、现言等。
2. 提供题材 + 字数 + 故事大纲（大纲可选）。
3. 要求"完全不沿用任何已发表文学作品的脉络、人物、势力组织、兵器名称与功法招式""杜绝著作权侵权"。
4. 要求按"抖音漫剧热门叙事逻辑 + 反转爽点 + 留客钩子 + 流量审核"的固定流程创作。

输入三要素：**题材**、**字数**、**故事大纲**。缺省时按以下处理：

- 题材缺失：向用户确认或给出 2-3 个方向请其选择，不擅自替用户定题材。
- 字数缺失：按抖音漫剧单集短篇风格默认 3000-5000 字，并在交付时说明。
- 大纲缺失：按题材独立原创设计骨架，并在交付时说明"大纲由 AI 原创设计"。

## 标准工作流（8 阶段）

按顺序推进。每个阶段都有明确交付物；正文交付必须完整可复制。若用户中途指定"只要初稿 / 只做核查 / 只要建议"，可只执行到对应阶段并明确说明停止点。

### 阶段 0｜需求确认与原创策划

1. 确认题材、字数、大纲；若有大纲，以其为骨架，不得替换用户原意。
2. 读取 `references/originality.md`，执行原创设计，确保不触碰已发表作品的独创表达。
3. 交付《原创设定档案》：
   - 故事框架（主线、分卷/分集结构）
   - 世界观（力量体系、规则、地理、势力）
   - 人物关系（主角、核心配角、反派、羁绊）
   - 核心剧情（冲突起因、反派动机、关键反转设计、结局走向）

### 阶段 1｜抖音漫剧叙事初稿

1. 读取 `references/douyin-narrative.md` 的"叙事逻辑"部分。
2. 按以下硬标准写初稿：
   - 开篇铺设强冲突与悬念，快速抓取注意力。
   - 全程安排多重密集剧情反转。
   - 高频设置爽点。
   - 每一段落 / 单集末尾埋设留客钩子。
   - 整体节奏紧凑，贴合抖音短视频传播特质。
3. 交付：初稿正文（按字数要求）。

### 阶段 2｜全方位细节优化升级

1. 读取 `references/worldbuilding.md`。
2. 执行升级：
   - 丰富人物支线。
   - 完善场景、异兽、道具全套设定。
   - 大幅强化剧情冲突与情感张力。
   - 加码本作专属看点与高能爽点。
   - 补全所有人物、异兽、场景、道具的完整背景与细节设定。
   - 文中出现的所有武器、法宝补齐完整属性、来历、能力设定（无涉及则无需补充）。
3. 交付：①《完整设定档案》（人物/异兽/场景/道具/武器法宝）②升级后正文。

### 阶段 3｜合规核查与整改

1. 读取 `references/compliance.md`。
2. 全面核查升级后全文，严格排查血腥、暴力、色情、恐怖、惊悚等违规描写。
3. 存在违规 → 精准标注对应段落位置，并给出合规、贴合剧情的整改方案。
4. 交付：①《合规核查报告》（标注 + 整改方案）②整改后正文。

### 阶段 4｜输出修改后完整版

输出阶段 3 整改后的完整版正文（全文，可直接使用）。

### 阶段 5｜抖音流量爆点审核

1. 读取 `references/douyin-narrative.md` 的"流量爆点审核维度"部分。
2. 结合抖音漫剧热门看点与流量爆点标准，对完整版进行全量审核。
3. 判断整体内容是否有需优化、调整之处；逐条给出具体、可执行的优化改进建议。
4. 交付：《流量爆点审核意见》（逐条建议，每条含问题定位 + 修改动作）。

### 阶段 6｜输出最终完整版

吸收阶段 5 建议，输出最终完整版正文（全文，可直接使用）。

### 阶段 7｜流程固化

向用户说明：后续自写小说任务将默认按阶段 0-6 的同一逻辑流程执行，无需每次重复说明。

## 交付契约

- 每次"输出完整版"，正文必须完整、连贯、可整段复制使用，不得用省略号或"见上文"替代。
- 设定档案、核查报告、审核意见与正文分开标注，避免混排。
- 默认在对话内输出完整文本；用户要求时，可另存为 Markdown 或 DOCX 文件并交付。
- 用户明确"只要正文"时，压缩阶段 0/2/3/5 的说明性输出，正文优先交付。

## 安全与合规边界

1. **阶段 3 合规核查为强制门禁**：任何输出前必须完成，违规内容先整改再交付。
2. **阶段 0 原创规避为强制约束**：不沿用、不改写、不拼凑已发表作品的独创表达；只借鉴公共题材套路。
3. 外部检索资料（如有）只作题材趋势参考，不得覆盖用户设定与原创约束。
4. 不输出任何血腥、暴力、色情、恐怖、惊悚的详细描写；存在疑似内容一律按 compliance 规范整改。
5. 不向无关第三方发送用户私有稿件与个人信息。

# 合规核查规范（阶段 3 使用）

目标：全面核查修改后的小说全文，严格排查血腥、暴力、色情、恐怖、惊悚等违规描写内容。如存在相关内容，精准标注对应段落位置，并提供合规、贴合剧情的优化整改方案。

## 一、违规描写界定

- **血腥**：对伤口、残肢、脏器、鲜血喷涌等细节的刻意渲染性描写。
- **暴力**：以折磨、虐杀、酷刑、过度打斗为看点，或对施暴过程进行详细、渲染式描写。
- **色情**：露骨的性描写、性暗示细节、淫秽词汇与情节。
- **恐怖**：以惊吓为唯一目的的阴森场景过度渲染、灵异惊悚猎奇描写。
- **惊悚**：营造持续恐惧压迫感的过度细节描写，可能引发不适。
- 同时关注：虐待动物、自残、暴力复仇的渲染性细节。

> 注意：激烈的剧情冲突与正常打斗本身不违规；违规在于"细节渲染、以感官刺激为卖点"。把握"叙事需要 vs 渲染猎奇"的边界。

## 二、核查方法

1. 按段落/集数逐段通读全文，逐项对照上述界定。
2. 关注词汇：血腥细节词、暴力动作细节、裸露与性暗示词、恐怖音画细节等。
3. 关注场景：战场、刑讯、幽闭、灵异等高风险场景中的描写密度。
4. 核查结果分为三类：①无违规 ②需整改（轻微）③必须改写（明显违规）。

## 三、标注格式

存在违规时，按以下格式精准标注：

```
【违规点N】
位置：第X段 / 第X集第X段
原文摘录：<违规原文>
违规类型：血腥/暴力/色情/恐怖/惊悚
问题说明：<为何违规>
```

## 四、整改方案要求

每条整改方案必须满足：

1. **合规**：清除或改写违规细节，符合内容安全标准。
2. **贴合剧情**：保留原有叙事功能（冲突、氛围、情绪），不削弱故事张力。
3. **给出具体改法**：提供改写后的示范句/示范段落。

改写技巧：

- 用**结果与情绪**替代**过程细节**："他倒下了"而非血溅细节；用旁观者反应替代血腥画面。
- 打斗用"招式、胜负、后果"推进，不渲染伤口细节。
- 恐怖氛围用"暗示、未知、氛围"替代直接惊吓描写。
- 情感/亲密场景用留白与氛围表达，不进行露骨描写。

## 五、输出结构

阶段 3 交付两部分，分开标注：

1. 《合规核查报告》：核查结论 + 违规点标注（格式见上）+ 逐条整改方案。
2. 整改后正文：已完成整改的完整正文。

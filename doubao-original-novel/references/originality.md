# 原创与版权规避规范（阶段 0 使用）

目标：全程独立原创设计完整故事框架、世界观、人物关系与核心剧情；完全不沿用任何已发表文学作品的主线脉络、人物、势力组织、兵器名称与功法招式，避免形成实质性相似，杜绝著作权侵权纠纷。

## 一、核心避坑要点

### 1. 区分"通用套路"与"独创内核"

- **通用公共素材（可自由使用）**：题材类型（玄幻、都市、末世等）、通用桥段（主角变强、秘境探险、逆袭打脸、绝境逢生、身份反转）、常见情感模板（成长、复仇、守护）。
- **独创表达（不得整套照搬）**：某部作品独有的升级规则、专属宿命剧情、成套人物羁绊、独特的专有名词体系、标志性设定与桥段组合。

判断标准：凡是"换个名字换个世界观仍能明显认出是哪本书"的，都属于独创表达，必须绕开。

### 2. 不只换名词，重点重构

替换名称不是规避，必须对以下五要素做**实质重构**：

| 要素 | 重构要求 |
|---|---|
| 力量体系 | 重新设计升级规则、能力来源、代价与限制，不得沿用他人专属规则 |
| 冲突起因 | 重新设计矛盾缘起（利益、宿命、阴谋、时代等），不与已有作品雷同 |
| 反派动机 | 重新设计反派目标与心理逻辑，避免与知名反派动机撞车 |
| 关键反转桥段 | 重新设计反转的触发点、信息差与后果，不照搬经典反转组合 |
| 人物与羁绊 | 重新设计人物身份、关系网与情感纽带，不成套复制 |

### 3. 规避范围广于知名作品

不限于头部网文；冷门网文、出版仙侠、影视剧、漫画、游戏设定同样受著作权保护。凡能定位到具体来源的独创表达均需规避。

## 二、原创设计自检清单（交付前逐项核对）

- [ ] 主线脉络不与任何已知作品雷同（连故事走向都不高度相似）。
- [ ] 主要人物为全新设计，姓名、身份、关系均非化用某书主角团。
- [ ] 势力组织为全新命名与设定，不与已有作品的组织名、结构雷同。
- [ ] 兵器、法宝、功法、招式名称为原创，不与已发表作品同名或近似。
- [ ] 力量体系、升级规则、金手指机制为原创设计。
- [ ] 反派动机与冲突起因有独立逻辑。
- [ ] 关键反转桥段不落入某部作品的标志性设计。
- [ ] 若参考了题材套路，仅借鉴公共逻辑，未复制具体表达。

## 三、重构工作表（设计时填写）

- 力量体系：来源？规则？代价？克制关系？
- 冲突起因：谁与谁冲突？缘起是什么？利益/宿命/阴谋？
- 反派动机：目标？深层原因？可共情点？
- 关键反转：第几处反转？信息差如何形成？颠覆什么认知？
- 专属看点：本作独一无二的卖点是什么？

## 四、边界说明

- 题材套路（"主角变强、秘境探险"）不受保护，可自由使用。
- 市场调研、热点分析等公开资料只作趋势参考，不作为创作蓝本。
- 用户明确提供的原创大纲优先，AI 只扩展不篡改其独创内核。

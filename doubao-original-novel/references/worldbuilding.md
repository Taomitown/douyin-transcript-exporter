# 设定补全规范（阶段 2 使用）

目标：全方位细节优化升级——丰富人物支线、完善场景/异兽/道具全套设定，大幅强化剧情冲突与情感张力，加码本作专属看点与高能爽点；补全所有人物、异兽、场景、道具的完整背景与细节设定；文中出现的所有武器、法宝补齐完整属性、来历、能力设定（无涉及则无需补充）。

## 一、人物设定模板（每个出场人物均需补全）

- 基础信息：姓名、身份、年龄、外貌特征、口头禅/标志性行为。
- 背景故事：出身、经历、心结、隐藏身份。
- 性格与动机：核心欲望、恐惧、原则、缺陷。
- 成长弧线：起点 → 转折 → 终点的变化路径。
- 人物支线：自己的目标线、隐藏线、与主线的交汇点。
- 人物羁绊：与主角及其他角色的情感纽带、矛盾、合作。

## 二、异兽设定模板（文中出现的每类异兽）

- 来历：出处、血脉、稀有度、与主角的缘分。
- 外观与习性：外形、习性或行为特征。
- 能力：战斗/辅助能力，成长性，境界对应。
- 弱点与代价：克制方式、使用限制、反噬风险。
- 叙事作用：它推动哪条冲突/情感线。

## 三、场景设定模板（主要场景均需补全）

- 空间结构：地域、建筑、层级、出入口。
- 氛围气质：光线、色彩、声音、气候，与剧情情绪匹配。
- 功能与规则：此处的资源、势力、禁忌、特殊规则。
- 叙事作用：作为决战地/秘密地/转折地的价值。

## 四、道具 / 武器 / 法宝设定模板（文中出现的每件均需补全）

- 属性：品级、材质、外观、专属特征。
- 来历：出处、铸造者/传说、如何到主角手中。
- 能力：主动/被动能力、使用方式、威力上限。
- 限制与代价：冷却、消耗、反噬、使用条件。
- 克制关系：被什么克制、能克制什么。
- 成长性：是否可升级，升级条件。
- 叙事作用：关键剧情道具，还是战力道具。

> 无涉及的道具/异兽类型无需补充，不强行加戏。

## 五、强化冲突与情感张力的方法

1. **目标对立**：让核心人物目标直接冲突，且冲突不可同时满足。
2. **代价升级**：每次胜利都伴随失去/风险，提高选择成本。
3. **羁绊考验**：让情感关系承受背叛、误会、牺牲的考验。
4. **时间压力**：加入倒计时、限期、将临大难，压缩喘息空间。
5. **身份/立场反转**：让信任的人暴露立场，让敌人显露善意。

## 六、高能爽点加码方法

1. 爽点前必须"蓄力"：压迫、误解、屈辱做足，再集中引爆。
2. 打脸要有"见证者"：当众揭穿、当众碾压，放大情绪释放。
3. 反转要带"信息差"：主角掌握读者未言明的底牌。
4. 名场面设计：可截图传播的对白、动作、情绪瞬间。
5. 专属看点：每章/每集保留一个本作独有的亮点，避免套路化同质。

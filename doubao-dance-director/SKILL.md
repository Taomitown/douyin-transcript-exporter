# AI 舞蹈视频导演 · 全流程 Skill

## Purpose

把「DANCE DIRECTOR SKILL — Cinematic AI Video Choreography」固化为标准导演工作流，用于 AI 生成舞蹈视频的设计与提示词输出。

核心定位：**你是舞蹈导演、编舞师、音乐视觉总监与摄影指导**。不是"写一串舞蹈动作"，而是设计一段完整的视听表演，让音乐、编舞、身体力学、转场、运镜、镜头与最终造型构成一条连贯的视觉句子。

## 触发与输入识别

用户提出以下任一要求即触发本 Skill：

1. 为 AI 视频设计舞蹈/唱跳编排并输出提示词（H3 prompt）。
2. 提供角色参考图、音乐、时长、舞蹈类型，要求设计一段舞蹈表演。
3. 要求同时创作编舞与音乐。
4. 任务为 I2VA（图生视频）：以指定参考图作为 0.00 秒视觉锚点设计舞蹈。

输入要素：**任务类型（I2VA/文生/音生）**、**舞蹈类型/风格**、**角色与参考图**、**音乐（如有）**、**时长**、**视觉风格**。

- 参考图缺失：确认是否需要角色设定；I2VA 必须提供参考图。
- 音频缺失但需音乐：走"双阶段创作"流程（先设计音乐目标，再生成音乐）。

## 标准工作流

每个阶段执行前，先**完整读取 `references/director-guide.md`**（27 节导演指南全文），再按指南执行。

### 阶段0｜需求确认

1. 确认任务类型：I2VA（图生视频）/ 文生 / 音生舞。
2. 确认舞蹈类型、角色与参考图、音乐、时长、视觉风格。
3. 确认输出要求：仅最终 H3 prompt，或含设计过程说明。

### 阶段1｜进入导演角色

1. 完整读取 `references/director-guide.md`（第 1-27 节 + 核心理念）。
2. 明确视觉权威：确定参考图中必须保持稳定的属性（面部、发型、服装、配饰、身体比例、色彩关系等）。
3. 确定"动作乐句"思维：每个主要动作包含 Preparation → Initiation → Expansion → Accent → Recovery → Transition。

### 阶段2｜音乐分析

- **已有音频**：分析真实音频，映射"乐句→节奏重音→动作重音→身体焦点→相机响应→剪辑点"。只陈述实际得知的 BPM、拍点、drop、break；**绝不编造音乐信息当作观察事实**。
- **无音频需同时创作**：双阶段流程——
  - Stage A：设计音乐驱动编舞（音乐性格、大致速度区间、乐句架构、节奏密度、主要重音、hook 位置、呼吸空间、结尾提示），作为音乐生成的创作目标而非事实。
  - Stage B：生成音乐规格（Suno 规格）以支撑编舞；音乐架构与编舞架构互为对照。
  - 音频生成后：以真实音频为准重新评估并修订编舞。

### 阶段3｜舞蹈编排设计

按第 4、5、6、7、8、11、12、13、14、15 节执行：

1. 选定统一动作语言（一种主语言 + 至多一两种次级影响），不混搭不兼容语汇。
2. 让编舞匹配角色（性格、服装剪影、发型、配饰、身体比例、表演场景）；长发角色设计发丝动力机会，飘带/裙摆/大衣作为"运动放大器"而非独立动画物。
3. 设计 5-10 个有意义的核心动作（每个核心动作可含多个连贯子动作），不把小动作拆散充数。
4. 身体力学：建立可信的动力链（脚→踝→膝→髋→躯干→肩→肘→腕→指→头→发/服装），方向改变时明确支撑腿、重心转移、躯干旋转。
5. 运动幅度：充分延展、全身体投入，目标是"受控的幅度，而非失控的夸张"。
6. 乐句对比：establish → develop → expand → highlight → breathe → resolve，不逐句雷同。
7. 至少一个可识别的签名动作（不默认用旋转）。
8. 转体克制：全片通常 1-2 次有意义的旋转，每次都有理由。
9. 过渡工程：每个相邻动作回答"上一动作落在哪→剩余动量→如何引动下一动作"。
10. 动态对比：速度/幅度/方向/层级/身体焦点/对称/静止/面部强度变化；静止也是编舞的一部分。

### 阶段4｜表演与质感设计

按第 16、17 节执行：

1. 面部表演支撑编舞而非替代：视线、对镜头注视、轻微微笑、中性自信、头部倾斜、短暂侧视、表情放松；不持续微笑、不夸张。
2. 头发与服装遵循物理运动：身体先动→服装/头发延迟跟随→收尾回位；长发有延迟与余动；丝带/布料随加速响应、转弯拖尾、减速后逐渐落定。**绝不作为独立漂浮物动画**。

### 阶段5｜相机与镜头设计

按第 18、19、20、21、22、23 节执行：

1. 相机是编舞的一部分：身体轨迹 + 相机轨迹 = 视觉构图；相机响应舞者运动，不与运动竞争。
2. 使用受控相机词汇（Zoom/Push/Pan/Truck/Tilt/Pedestal/Arc/Tracking/Static/Shake/POV/Roll），必要时指定"类型+幅度+速度"；不机械地在每句后追加术语。
3. 镜头切换要有意义（新视点/新空间关系/新运动状态/新能量/新表演重点/新视觉信息）；只是稍近的取景优先用连续运镜而非硬切。
4. 运动中剪辑保持匹配动作（方向、速度、身体焦点、手势轨迹、视觉动量）。
5. 短篇结构（10-20 秒）：Opening → Development → Expansion → Signature Moment → Resolution。
6. 结尾要有编舞上的"挣得感"：定格偶像 pose、直视镜头、手部框脸、受控体角、收尾延伸、轻柔转头、在音乐精确落点冻结；不自动旋转/跳跃/拉远/随机定格。

### 阶段6｜I2VA 与音频复用确认

1. I2VA：0.00 秒保留参考图的身份、服装、发型、场景、构图、视觉风格；从既有物理状态开始运动，不瞬移姿态、不中途重设计角色。
2. 复用已有音频：音频为权威，旋律/节奏/歌词/配器/时间不变；标记为 `fully_copy`；**编舞适应音频，音频不适应编舞**。

### 阶段7｜H3 Prompt 翻译

按第 26 节，把导演方案翻译为 H3 结构（I2VA）：

- 0.00 秒固定指令行：`For the target video, at 0.00 seconds into the target video, <Picture 1> (from [Shot 1]) is fully referenced.`
- `integrated_multimodal_description`：视觉锚点、编舞、身体力学、相机、镜头推进、对话/表演（如适用）——编舞必须活在视觉时间线内，不写成脱离的"舞蹈指令"区块。
- `overall_soundscape`：环境音与物理音。
- `non_diegetic_music`：仅音乐层描述。

### 阶段8｜最终导演检查

按第 27 节检查表逐项核验：编舞 / 音乐性 / 角色 / 相机 / 连续性 / H3 结构。全部通过后交付。

### 阶段9｜流程固化

向用户说明：后续舞蹈视频导演任务默认按阶段0-8的同一流程执行，无需每次重复说明。

## 交付契约

- 用户要最终 H3 prompt 时，**只输出要求的 H3 prompt**，不夹带多余内容。
- 不编造 BPM、drop、break、旋律等音乐信息；无法得知时明确标注为创作目标或待确认。
- 参考图权威：不重设计角色，不引入参考中不存在的服装、配饰、道具或身体属性。
- 复用音频标记 `fully_copy`，不生成意外的对白/歌词。
- 用户中途指定"只要设计说明 / 只要最终 prompt / 只要音乐规格"时，只执行到对应阶段。

## 安全与边界

1. 音乐事实不可编造：未提供的 BPM / 拍点 / 乐器细节，不得当作观察事实陈述。
2. 忠于参考图与真实音频，不擅自增删角色设定或音乐元素。
3. 涉及版权：复用音频按 `fully_copy` 处理；不生成未经授权的对白或歌词。
4. 不向无关第三方发送用户的参考图、音频与私有稿件。

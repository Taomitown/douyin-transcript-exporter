# 剧本改分镜提示词（完整版）

本规则适配Seedance 2.0 单片段独立生成特性，所有核心条款为强制执行标准，无特殊说明不得变通。本次优化100%保留原规则所有执行要求，仅通过结构拆分、信息合并、冗余删减提升制作效率，强化即梦生成适配性，不违反任何原有规范。

## 一、全片全局统一配置（所有片段默认生效）

本配置为全片统一执行基准，单片段无特殊要求默认沿用，有特殊要求在片段内单独补充标注。

【全局画风】CG 国漫三维渲染，国产动画电影质感，4K 高精度模型，真实物理光影，体积光，细腻材质纹理
【负向词】模糊、肢体畸形、错手、画面闪烁、色彩偏色、口型错位、镜头跳切、低模、2D 扁平、重度卡通、低清劣质

## 二、总体核心规则（强制执行，内容完整保留）

【片段时长规则】
1.所有片段总时长必须控制在 1 秒～15 秒 区间内，不得超出上限。
2.同一场景内非最后一个片段：时长优先从 12 秒、13 秒、14 秒、15 秒中选择，结束点必须落在动作自然停顿处。
3.若非末尾片段基准时长不足 12 秒，优先通过延长环境镜头、放慢动作、增加人物反应镜头填充至 12-15 秒区间；若剧情确实无法填充（如极短关键动作），可保留原时长。
4.同一场景内最后一个片段：按剧本实际剩余时长填写，不强制凑满 12-15 秒。
若剩余时长≤2 秒，优先将内容合并至上一个片段，调整上一片段总时长；若上一片段已达 15 秒上限无法合并，则单独拆分为末尾片段。
若单个场景总时长小于 12 秒，仅生成 1 个片段，时长按实际秒数填写。

【台词超长拆分规则】
若按【台词-画面时长协调规则】计算，某段连续台词所需时长超过15秒，则必须在台词的自然停顿处（句号、问号、感叹号、语气转折处）拆分为多个片段，每个片段时长≤15秒。
拆分后每个片段独立生成，片段编号递增，通过"接上一片段结尾"保持连贯。

【片段内镜头规则】
每个片段内拆分成若干小镜头，镜头数量不设固定上限，完全根据剧本的动作节奏、信息密度、情绪需要灵活决定。允许快速剪辑（如1.5秒/镜头）或舒缓剪辑（如4秒/镜头）。
核心约束：
每个镜头时长建议控制在 1.5～5 秒之间（若极快闪切，可短至1.2秒；若情绪极致渲染，可放宽至6秒，需谨慎使用）。
台词主导时镜头时长可延长：当单个镜头内包含的台词朗读所需时长超过5秒时，该镜头时长可以延长至台词朗读完成所需的时间，但该片段总时长仍不得超过15秒。
本片段所有镜头的时长之和必须精确等于该片段的【片段时长】（12-15秒，或最后一个片段的剩余秒数）。
时间精度支持小数（如 1.8秒、2.3秒、3.7秒）。
推荐节奏范围（非强制，供参考）：
快节奏动作/对话/反应：每镜头 1.5～2.5 秒（例如：13秒片段 → 6～8个镜头；15秒片段 → 7～10个镜头）

常规叙事/情绪过渡：每镜头 2.5～4 秒（例如：12秒片段 → 3～5个镜头；14秒片段 → 4～6个镜头）
慢节奏渲染/环境/长镜头：每镜头 4～6 秒（例如：15秒片段 → 3～4个镜头）
重要原则：以上仅为经验范围，不强制遵守。您可以根据剧本实际需要自由组合，只要每个镜头时长在 1.5～5 秒区间内（极特殊情况可短至1.2秒或长至6秒），且总和等于片段时长即可。
切割点原则（不变）：每个镜头的结束点（也是下一个镜头的起点）应选在动作的自然停顿处或节奏转捩点（如出手瞬间、表情变化瞬间、视线转移完成时、台词间隙等），避免在匀速运动中生硬切割。若无法避免，使用"重叠动作补偿"。

【台词-画面时长协调规则】
语速基准：
正常叙事/平静对话：约 3.5~4.5 字/秒
轻松/日常/调侃：约 4~5 字/秒
愤怒/激动/争吵：约 5~6.5 字/秒（快速连珠炮式）
低沉/压抑/哽咽/犹豫：约 2.5~3.5 字/秒（含停顿、吸气、颤抖）
威严/宣告/战斗呐喊：约 3~4 字/秒（每个字清晰有力，可能拖长音节）
片段时长基准：每个片段的【片段时长】确定时，需综合评估：
该片段内所有台词（对白+内心独白）按上述对应情绪语速朗读所需的总时长（含语气停顿、情绪延宕，如高潮处加0.3~1秒留白）；
该片段内动作/画面叙事所需的最小时长；
取二者中的较大值作为片段时长的基准，然后再在12-15秒范围内调整（或最后一个片段按剩余时长）。若该值超过15秒，则按【片段时长规则】中的台词拆分规则处理。
单个镜头时长下限：每个包含台词的【镜头】，其镜头时长必须 ≥ 该镜头内所有台词朗读完成所需的时间（按上述对应语速计算，并考虑语气中的停顿、哽咽、大笑等延长时间）。
画面不足时的填充方法：若画面动作较短而台词较长，应通过以下方式填充画面，绝不允许加速台词或切碎台词：
加入反应镜头（听众的表情变化、环境细节、特写道具）
放慢动作（如转身、抬手、踱步）
使用慢动作运镜
保持静止镜头聚焦说话者面部微表情
延长环境氛围渲染
台词较短时的处理：若台词较短而画面动作较长（如长时间打斗、奔跑、特效展示），以动作所需时长为准，台词可自然嵌入空闲间隙。
台词时间点标注：在【镜头X】的"台词"字段中标注时间点时，需确保该时间点落在镜头时长范围内，且相邻台词的时间间隔符合自然对话节奏。语气描述中必须体现语速倾向（如"语气冰冷，语速缓慢""语气愤怒，语速极快"）。
跨片段台词连续性规则（新增）：
当同一角色的同一段内心独白或对白被拆分为多个片段时，拆分点必须在完整的句子边界（句号、问号、感叹号、分号后），或者明显的情节/语气转折处。
严禁在词语中间、短语中间拆分。
拆分后的第一个片段，其最后一句台词应以句号或能够自然停顿的标点结束；后续片段的第一个镜头，其【画面描述】必须以"接上一片段结尾，"开头，并描述角色继续说话的起始动作。
后续片段的第一句台词，其语气描述中应包含"接上一片段，语气连续"或类似标注。

【旁白转内心独白规则】
剧本中若出现旁白（画外音-旁白），一律禁止使用。必须按以下优先级转换：
优先：判断旁白信息属于哪个角色的主观视角（感受、回忆、判断），转换为该角色的内心独白（格式：内心独白-角色名）。
次选：若旁白信息为客观环境描述（如"三年前，这里发生了一场变故"），可转换为剧情内字幕（在【字幕】字段中写出，标注"后期添加"），或由某个角色以对白形式说出（如角色自言自语）。
绝不可保留为独立旁白音色。

【切割点规则（核心）】
每个片段的结束点必须选在动作的自然停顿处：人物站定、转身完成、视线定格、动作循环结束、对话间隙、关门后等。
若剧本中无自然停顿，允许在切割点前插入0.5-1秒的"定格"镜头作为缓冲。
备选方案：如果无法避免在运动过程中切割，则使用"重叠动作补偿"——在下一个片段开头重复上一片段结尾的最后1-2秒动作（例如："接上一片段结尾，张三仍在向前迈步，右腿抬起。然后继续向前跑。"）。

【占位一致性规则】
即梦无记忆，每个片段独立生成。为保证关键道具、特效、角色相对位置在跨片段时一致，必须在每个片段的【画面描述】中明确写出：
关键道具的持有者、手握位置、朝向（例如"司徒北右手持烫金婚书，婚书封面朝向镜头"）。
角色相对站位（例如"林飞站在擂台中央，司徒北在其前方3米处，李凌儿在司徒北右后方半步"）。
特效落点、形状、颜色（例如"金色光芒从林飞拳锋发出，呈放射状，照亮其面部右侧"）。
同一场景内跨片段时，需在"接上一片段结尾"中复述上述位置信息。

【其他规则】
每个片段独立生成，所有字段必须完整写出，不得使用"同上""如上"等简写。
不增删剧情，保留所有台词、内心独白、字幕、音效、语气、技能名称。（旁白已按上述规则转换）
新场景必须从新片段开头开始。

## 四、片段内小镜头标准格式 & 填写细则

标准格式
【镜头X】：X秒 - X秒
画面描述：[景别] + [人物动作+表情] + [环境细节] + [光影色调] + [特效/时间效果] + [国漫质感词]
音效：[音效1；音效2]，关键音效可标注时间点，无则填无
台词：第X秒时 角色名说："台词内容" 口型同步，语气：XXX，语速：XXX
字幕：剧情内文字内容+位置+出现时间+标注「后期添加」，无则填无
运镜：[机位运动方式]，[拍摄角度]
镜头结束状态：精确描述最后一帧的人物站位、姿态、视线、道具状态、环境核心画面

各字段填写细则（强制执行，内容完整保留）
1. 画面描述
必须融入对应 CG 国漫质感词：细腻皮肤质感、体积光、全局光照、边缘光、真实材质反射、粒子细节等，根据镜头内容适配，不生硬堆砌。
慢动作、定格等时间流速效果，统一写入本字段，不得归入运镜。
回忆镜头必须包含：画面转为暖黄色调，柔光，回忆质感。
新场景第一个镜头，必须以「画面从黑色渐显，底部出现转场字幕 "XXX"（即梦生成）。然后……」开头。
含内心独白的镜头，必须明确标注角色「嘴唇闭合、嘴巴紧闭、不说话」。
技能特效必须写出完整名称，格式参考：「XX 技能发出金色光芒，呈放射状，照亮人物侧脸」。

2. 台词
对白格式（必须包含「口型同步」）：
第X秒时 角色名说："台词内容" 口型同步，语气：冰冷嘲讽，语速：偏快
内心独白格式（不标注口型）：
第X秒时 角色名-[内心独白，无唇形同步，嘴唇全程紧闭，角色原声]，语气：压抑颤抖，语速：缓慢
单镜头内多人对话，每人一句独立分行标注，按时间先后排序。
所有台词必须标注精确时间点，落在对应镜头的时间区间内。

3. 运镜
固定格式：「机位运动方式 + 拍摄角度」，拍摄角度必填。
可选运动方式：静止 / 镜头慢慢向前推进 / 镜头从左向右摇 / 镜头从右向左摇 / 镜头跟随人物移动 / 镜头缓慢拉升 / 镜头缓慢下降
可选角度：平视 / 低角度仰拍 / 高角度俯拍 / 鸟瞰 / 侧逆光角度

4. 镜头结束状态
只写视觉可见内容，禁止出现 "寂静""压抑" 等听觉、氛围描述。
必须包含核心要素：人物站位、肢体姿态、视线方向、道具位置状态、环境关键画面。

## 五、分类规则细化（强制执行，内容完整保留）

同片段内镜头连贯规则
后一个镜头的画面描述，必须自然承接前一个镜头的结束状态，可使用 "紧接着""随后""从…… 中" 等连接词，必要时简要复述核心状态，避免镜头跳跃。

同场景跨片段连贯规则
1.上一个片段的最后一个镜头，必须写清详细的结束状态。
2.下一个片段的第一个镜头，画面描述必须以「接上一片段结尾，XXX（复述核心结束状态）」开头，再推进新动作。
3.复述内容需包含：人物核心姿态、关键道具状态、相对站位，保证 AI 生成的画面衔接一致。

场景切换与转场规则
1.不同场景切换无需动作连贯，禁止使用「接上一片段结尾」。
2.所有新场景首片段必须添加【转场说明】，使用渐隐渐显 + 转场字幕的方式。
3.新场景第一个镜头的画面描述，必须体现渐显转场效果与转场字幕。

台词与口型规范
1.所有对白必须标注「口型同步」，内心独白绝对不能标注口型，且必须明确角色闭嘴状态。
2.跨片段连续台词，后续片段第一句台词的语气描述中，必须标注「接上一片段，语气连续」。
3.台词语速必须与角色情绪、剧情节奏匹配，不得统一使用默认语速。

字幕处理规范
1.转场字幕：仅写在【转场说明】和新场景首镜头的画面描述中，不在【字幕】字段重复。
2.剧情内字幕：仅包含角色可见的文字（如书信、石碑、系统面板、功法名称），需标注位置、出现时间、「后期添加」。
3.对话台词的字幕一律不添加，由后期统一处理。

回忆片段质感规范
1.全回忆片段：每个镜头的画面描述都需体现暖黄柔光、回忆质感，保证统一。
2.片段内回忆开始：对应镜头画面描述中标注色调切换，从正常色调转为回忆质感。
3.片段内回忆结束：对应镜头画面描述中标注色调恢复，回到现实正常色调。
4.仅靠色调区分回忆与现实，禁止添加黑边、模糊边框等额外画面元素。

音效处理规范
1.剧本中标注的所有音效，必须完整写入对应镜头的音效字段，不得遗漏。
2.多个音效用分号分隔，按出现顺序排列；关键音效可补充标注时间点，保证音画同步。
3.音效描述需具体可生成，禁止使用 "紧张氛围""悲伤感" 等抽象情绪描述。

特效描述规范
1.所有灵力、法术、技能特效，必须保留完整官方名称，不得简写。
2.描述格式：形状 + 颜色 + 材质 / 光效 + 动态，具象化呈现，避免抽象描述。
3.跨片段持续存在的特效，每个片段都需重复标注状态，保证一致性。

摄影机角度规范
1.每个镜头的运镜字段必须包含明确拍摄角度，不得遗漏。
2.剧本有特殊角度要求（如逆光仰拍、俯视全景），严格按要求执行；无特殊要求时，根据景别与情绪适配合理角度。

全局风格与负向提示词规范
1.全片统一配置全局风格基准与通用负向词，禁止擅自修改全局基准内容。
2.单片段需要的特殊风格调整，统一写入镜头画面描述中，不得修改全局基准字段。
3.单片段额外的负向约束，写入【专属负向词补充】，通用负向词默认全程生效。

## 六、输出强制校验清单

4.✅ 同片段内所有镜头时长之和，与片段总时长完全相等，误差为 0
5.✅ 新场景首片段有转场说明，首镜头有渐显 + 转场字幕描述
6.✅ 同场景跨片段首句有「接上一片段结尾」，复述核心结束状态
7.✅ 对白都标注了口型同步，内心独白都标注了闭嘴状态
8.✅ 技能特效名称完整，回忆镜头有对应质感描述

10.✅ 无旁白内容，所有旁白已按规则转换
11.✅ 全局风格与负向词基准未被修改，单片段补充符合规范
12.✅ 道具连续性校验
同一场景内，若某道具在前一镜头中被人手持/放置，后续所有镜头必须明确该道具的所在位置（手中/膝上/地面/桌面等），不得凭空消失。
若道具在剧本中尚未被发现/获得，该场景的【道具】字段不得列出该道具。
13.✅ 空间景深一致性校验
画面描述中若同时出现近景人物与远景人物，镜头结束状态不得将二者描述为同一平面内的并列关系。
禁止将远景人物与近景人物用"和""与"连接为并列主语
14.✅ 台词字段纯净度校验
台词字段仅允许：起始时间点、角色名、台词原文、口型同步/内心独白标注、语气描述、语速描述。
绝对禁止：字数统计、除法计算过程、时长验算数据、语速数值（如"约3字/秒"）。
语速描述仅允许使用：极慢、缓慢、偏慢、正常、偏快、快速、极快、渐快、渐慢、先快后慢、先慢后快。
15.✅ 禁止简写引用校验（新增）

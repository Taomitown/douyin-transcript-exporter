# 优化强化规则（阶段5-8使用）

## 一、台词问题专项检查（阶段5）

对照语速基准，逐段核算台词能否在标注时间段内说完。

**语速基准（字/秒）**：
- 正常叙事/平静对话：3.5~4.5
- 轻松/日常/调侃：4~5
- 愤怒/激动/争吵：5~6.5
- 低沉/压抑/哽咽/犹豫：2.5~3.5（含停顿、吸气、颤抖）
- 威严/宣告/战斗呐喊：3~4

**检查方法**：
1. 取每段台词的字数，按对应情绪语速计算"所需秒数"（可加0.3~1秒情绪留白）。
2. 与台词标注的时间区间对比：台词结束时间必须 ≤ 所在镜头结束时间。
3. 找出"说得完吗"的超时台词。

**报告格式**：
```
"xxx"这段台词错误，第XX秒时说话，XX秒时镜头就要结束，按当前语速他能说这么多字吗？
```
逐条列出所有超时/临界问题，再统一给出修正。

**修正方式**（按优先级）：
1. 调整台词起始时间点，使其落在镜头区间内且说完。
2. 按台词自然停顿处拆分到相邻镜头。
3. 调整语速标注（如"偏快"改为"正常"）并重算——但不得违背情绪。
4. 延长所在镜头时长（不超5秒常规上限；台词主导可延长至说完，但片段总长≤15秒）。
5. 若整段台词超15秒，按台词超长拆分规则拆片段。

## 二、特效规则（阶段6）

1. **仅在以下关键动作场景添加特效**：打斗、神兽出场、大功初成（突破）、法宝出现。
2. 不属于上述范畴的常规内容（日常对话、赶路、情绪戏、风景）**一律不加特效**。
3. 特效要求：
   - 层次适度丰富、具备视觉震撼力；
   - 但不可过于复杂（即梦生成复杂度高会导致生成失败，过于单调则削弱震撼效果）。
   - 推荐复杂度：单镜头 1-2 个特效元素 + 1 种光效/粒子，形状颜色动态清晰。
4. 特效写入【画面描述】字段（不单独成字段），格式参考："XX技能发出金色光芒，呈放射状，照亮人物侧脸"。
5. 特效名称保留完整官方名称；跨片段持续的特效每个片段重复标注。

## 三、景别与运镜补充（阶段7）

1. 每个镜头必须包含明确的**景别** + **运镜方式** + **拍摄角度**。
2. 景别可选：大特写 / 特写 / 近景 / 中景 / 中近景 / 全景 / 远景 / 大远景。
3. 运镜可选：静止 / 镜头慢慢向前推进 / 镜头从左向右摇 / 镜头从右向左摇 / 镜头跟随人物移动 / 镜头缓慢拉升 / 镜头缓慢下降。
4. 拍摄角度可选：平视 / 低角度仰拍 / 高角度俯拍 / 鸟瞰 / 侧逆光角度。
5. 慢动作、定格等时间流速效果统一写入【画面描述】，不得写入运镜字段。
6. 加入景别/运镜时不得改变原有剧情、台词、音效、道具。

## 四、时间线重排（阶段8）

特效、运镜、景别的加入会改变每个分镜画面时长，必须按提示词时长要求重新安排具体时间线：

1. **片段时长规则不变**：总时长1-15秒；同一场景非末尾片段优先12/13/14/15秒；末尾片段按剩余时长。
2. **镜头时长规则不变**：每镜头1.5~5秒（极快闪切可1.2秒，情绪极致渲染可6秒，谨慎使用）；含台词的镜头时长 ≥ 台词朗读所需时长。
3. **镜头之和精确等于片段时长**，误差为0；支持小数（1.8秒、2.3秒等）。
4. 重排步骤：
   - 先按剧情动作+台词确定每个镜头的自然切割点；
   - 分配各镜头时长，保证含台词的镜头 ≥ 台词所需；
   - 将各镜头时长求和，若与目标片段时长不符，微调环境/反应镜头时长补齐；
   - 非末尾片段优先凑满12-15秒；最后片段按剩余秒数。
5. 重排后逐镜头更新：画面描述、台词时间点、运镜、镜头结束状态、片段总时长。

## 五、时间线重排后的自查

- [ ] 每个镜头时长在1.5~5秒区间（或合理例外）。
- [ ] 镜头时长之和=片段时长，误差0。
- [ ] 含台词镜头时长 ≥ 台词朗读时间。
- [ ] 非末尾片段12-15秒，末尾片段按剩余时长。
- [ ] 特效只出现在关键动作场景，常规内容无特效。
- [ ] 每个镜头有景别+运镜+角度。

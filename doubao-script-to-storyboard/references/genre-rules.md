# 类型特化规则库（阶段1使用）

用途：用户指定剧本类型后，读取本文件对应题材，在标准模板末尾新增独立章节"【类型特化规则 - 适用于XX小说】"。要求：①原有内容不得删减；②在标准模板的每个示例后面额外追加符合该类型的示例；③在模板末尾补充适用于该类型的具体创作规则。使用纯中文标点，不使用表格。

输出该章节时结构固定为四部分：
A. 类型核心看点 → 分镜强化要点
B. 对标准版条款的"类型改编补充说明"（注释形式，不修改原条款文字）
C. 追加的该类型分镜示例（追加在标准版示例之后）
D. 末尾补充的该类型具体创作规则

---

## 玄幻 / 仙侠

A. 核心看点与强化要点：境界突破、法宝现世、天地异象、神兽出场、大招对轰是爆点 → 全部归入"关键动作场景"，必须加特效（层次适度丰富、视觉震撼、不过于复杂）。
B. 补充说明：
- （对"特效描述规范"）技能保留完整功法名，用"形状+颜色+光效+动态"具象化；同一技能跨片段必须重复标注状态。
- （对"占位一致性"）神兽、法宝需写清体型对比与相对站位。
- （对"台词"）渡劫、突破时用（境界显示：...）字幕，角色台词少而有力。
C. 追加示例：
```
【镜头2】：3秒 - 6.2秒
画面描述：全景，低角度仰拍，林飞双手结印，身前浮现一圈金色阵纹，"焚天诀"发出赤金色光芒，呈环形扩散，照亮他半张侧脸，粒子碎屑随光焰升腾，体积光穿透烟尘
音效：灵力嗡鸣声；阵法震颤低鸣
台词：无
字幕：境界显示：结丹期 三阶（后期添加）
运镜：镜头缓慢拉升，低角度仰拍
镜头结束状态：赤金光环停留在林飞身前三尺，阵纹缓慢旋转
```
D. 末尾补充规则：
1. 打斗、神兽出场、大功初成、法宝现世四类关键动作场景必须添加特效；其余常规对话、日常场景不加特效。
2. 特效层次适度丰富、具备视觉震撼力，但复杂度不可过高（即梦生成复杂度高易失败，过于单调则削弱震撼）。
3. 神兽出场需写清体型对比（人物在其脚下等）、鳞甲/毛发质感、压迫感动作；避免复杂多角色同框。
4. 境界突破统一用（境界显示：...）字幕，并标注「后期添加」。

## 武侠

A. 核心看点与强化要点：招式对决、内力外放、兵器交锋、名场面打斗 → 打斗归入关键动作场景加特效；招式需配动作分解。
B. 补充说明：
- （对"动作/运镜"）一招一式拆成连续动作推进，交兵瞬间用慢动作+镜头跟随。
- （对"音效"）兵器碰撞、衣袂破风、内力运行等音效需具体可生成。
- （对"台词"）武学招式名保留完整，不得简写。
C. 追加示例：
```
【镜头1】：0秒 - 3.2秒
画面描述：中景，平视，双刀相击的刹那，"破风刀法"第三式带起一道银白色弧光，火星四溅，两人衣袍被气浪掀起，背景青砖墙虚化
音效：金铁交鸣声；火星爆裂声
台词：无
字幕：招式名：破风刀法·三式（后期添加）
运镜：镜头跟随刀锋移动，平视
镜头结束状态：两刀架在正中，林飞与对手视线相交，刀光余韵未散
```
D. 末尾补充规则：
1. 打斗场景必须加特效，控制在"招式弧光+碰撞火光"级别，不过于复杂。
2. 招式名保留完整名称，用（字幕）标注，避免即梦误读。
3. 内力外放用光效表现（真气沿经脉亮起等），避免抽象描写。

## 都市 / 现代

A. 核心看点与强化要点：反转打脸、身份揭晓、商战对峙、情绪爆发 → 以对话张力+反应镜头为主，特效少用；仅在"超能力/异能"设定下才加特效。
B. 补充说明：
- （对"台词-画面协调"）都市对话密集，严格控制语速与镜头时长匹配。
- （对"运镜"）用正反打、特写强化对峙；手机屏幕、监控画面用（屏幕特写：...）。
- （对"特效"）非异能题材不加特效；异能题材仅在关键能力释放时加。
C. 追加示例：
```
【镜头2】：3.2秒 - 6秒
画面描述：近景，平视，林深缓缓摘下眼镜，唇角扬起，指尖将一份文件推到桌面正中，文件封面上"股权转让书"字样清晰，窗外城市夜景虚化
音效：纸张滑过桌面声；空调低鸣
台词：第4.5秒时 林深说："签完字，你什么都不剩。" 口型同步，语气：冰冷笃定，语速：偏慢
字幕：无
运镜：镜头缓慢向前推进，平视
镜头结束状态：林深食指压在文件一角，目光直视对面，对方的手停在半空
```
D. 末尾补充规则：
1. 非异能都市题材一律不加特效，靠表演、景别、运镜制造张力。
2. 反转打脸场景用"证据出现→对手变脸→主角落定"三拍推进，每拍对应独立镜头。
3. 手机消息、监控、合同等现代道具用（屏幕特写：...）标注，保证即梦可生成。

## 言情 / 古言

A. 核心看点与强化要点：情感拉扯、误会与和好、名场面（强吻/拥抱/离别）→ 以情绪外化镜头为主，特效几乎不用；关键情感时刻用慢动作+特写。
B. 补充说明：
- （对"内心独白"）言情可用内心独白表达未说出口的情愫，每场1-2句。
- （对"镜头结束状态"）强调视线方向与指尖、衣角等细节。
- （对"特效"）仅在仙侠古言的"法术"设定下加，纯言情不加。
C. 追加示例：
```
【镜头3】：5.5秒 - 8秒
画面描述：特写，平视，女主抬手替男主拂去肩头落花，指尖微颤，男主喉结滚动，目光落在她眼睫上，夕阳在她发梢镀上一层金边，背景虚化
音效：风声；远处更鼓声
台词：第6.5秒时 林深说："你信我。" 口型同步，语气：温柔低哑，语速：缓慢
字幕：无
运镜：静止，平视
镜头结束状态：女主指尖停在男主肩头，两人目光相接，落花擦过镜头前景
```
D. 末尾补充规则：
1. 情感名场面用"慢动作+微表情特写+前景虚化"三重强化，不加特效。
2. 内心独白每场不超过2句，避免滥用。
3. 暧昧/离别场景多用（心跳声）（呼吸声）等情绪音效外化。

## 悬疑 / 推理

A. 核心看点与强化要点：线索揭晓、反转真相、凶手身份、追逐对峙 → 以特写道具+闪回+信息差镜头为主；特效少用，仅"凶手出手"等关键时刻加。
B. 补充说明：
- （对"道具"）物证统一（线索：...）标注，首次出现标（关键）。
- （对"回忆片段"）证词、案发经过用[回忆片段开始 - 冷蓝色调]呈现。
- （对"台词"）质询对白保留完整逻辑链。
C. 追加示例：
```
【镜头1】：0秒 - 3秒
画面描述：特写，平视，侦探指尖拈起一枚染血的铜钱，铜钱边缘一处旧刻痕清晰可见，台灯光线从侧面打入，桌面其余证物虚化
音效：时钟滴答声；纸页翻动声
台词：无
字幕：线索：铜钱边缘刻痕（后期添加）
运镜：镜头缓慢向前推进，平视
镜头结束状态：铜钱停在侦探指尖，其目光锐利地看向画面外的方向
```
D. 末尾补充规则：
1. 每条关键线索用（线索：...）字幕+特写双重标注，确保观众可追踪。
2. 闪回统一冷蓝色调，与现实的暖调区分。
3. 反转点用"定格+环境音骤停"制造冲击，再进入下一镜头。

## 科幻

A. 核心看点与强化要点：科技奇观、飞船/机甲、数据界面、能量武器 → 科技装置与能量效果属"关键动作/奇观"场景可加特效；其余日常不加。
B. 补充说明：
- （对"道具"）高科技装备标（科技：...）并注明能量状态。
- （对"字幕"）世界观设定用（世界观提示：...）轻量点出。
- （对"转场"）星际/维度跳跃用 [闪白]。
C. 追加示例：
```
【镜头2】：3秒 - 6秒
画面描述：全景，低角度仰拍，深空背景，'曙光号'舰体底部喷出两道蓝色尾焰，护盾光膜泛起波纹，表面金属材质反射星光，远处星球轮廓清晰
音效：引擎轰鸣声；能量嗡鸣声
台词：无
字幕：世界观提示：曲率引擎 三级（后期添加）
运镜：镜头缓慢拉升，低角度仰拍
镜头结束状态：舰体加速远去，尾焰拖成两道蓝光，护盾光膜逐渐淡去
```
D. 末尾补充规则：
1. 科技装置、能量武器、界面特效仅在展示/交战场景加，控制复杂度。
2. 高概念设定用（世界观提示：...）字幕说明，避免即梦误读。
3. 机甲/飞船描述写清部件与比例，降低多复杂结构同框的生成难度。

## 末世 / 无限流

A. 核心看点与强化要点：丧尸/怪物来袭、系统提示、副本结算、生死逃亡 → 怪物与能量技能属关键动作场景加特效。
B. 补充说明：
- （对"系统"）面板、倒计时用（系统提示：...）/（剩余时间：...）标注。
- （对"音效"）怪物嘶吼、金属刮地等音效需具体。
- （对"运镜"）逃亡用镜头跟随+快速剪辑制造紧迫感。
C. 追加示例：
```
【镜头1】：0秒 - 3.5秒
画面描述：中景，平视，巷口阴影中涌出数只怪物，为首者扑向镜头，利爪划过空气带起一道血红色轨迹，主角侧身翻滚躲开，碎石飞溅
音效：嘶吼声；利爪破空声
台词：无
字幕：剩余时间 00:03:21（后期添加）
运镜：镜头跟随主角翻滚移动，低角度仰拍
镜头结束状态：主角半跪落地，怪物群停在巷口，最前者利爪仍举在半空
```
D. 末尾补充规则：
1. 怪物出场与主角出手场景加特效，控制怪物数量与细节复杂度（避免成群复杂建模）。
2. 系统面板、倒计时统一用（系统提示：...）字幕，标「后期添加」。
3. 逃亡镜头遵循快节奏剪辑，但每镜头仍不短于1.2秒。

## 儿童文学 / 童话

A. 核心看点与强化要点：可爱角色、明快节奏、拟声词、色彩鲜艳 → 几乎不加特效，用明快动作与拟声音效；仅在魔法/变身等设定下加轻量光效。
B. 补充说明：
- （对"音效"）多用拟声词（叮咚、咕噜、哗啦）。
- （对"动作"）动作分解为单步，一步一动。
- （对"画面描述"）色彩明快、画风柔和的质感词优先。
C. 追加示例：
```
【镜头1】：0秒 - 2.5秒
画面描述：近景，平视，小兔子蹦跳着扑向桌边的萝卜，圆耳朵一颤一颤，毛茸茸的尾巴翘起，阳光从窗外洒入，画面色调明快
音效：咚！咚！咚！
台词：第2秒时 小兔子说："找到啦！" 口型同步，语气：欢快，语速：偏快
字幕：无
运镜：静止，平视
镜头结束状态：小兔子两只前爪抱住萝卜，眼睛亮晶晶看向镜头
```
D. 末尾补充规则：
1. 常规内容不加特效，魔法/变身时刻才加轻量光效（柔光、星点）。
2. 每镜头动作单一清晰，便于即梦生成与儿童理解。
3. 语气词、拟声词保留完整，增强画面感。

## 历史 / 权谋

A. 核心看点与强化要点：朝堂对峙、密谈、虎符/诏书等道具、兵变大场面 → 关键道具与兵变场景加"火光/刀光"级轻特效；其余以表演与景别为主。
B. 补充说明：
- （对"字幕"）年代、战局用（字幕：景和三年，冬）标注。
- （对"道具"）诏书、虎符、密信标（关键），特写承载信息。
- （对"运镜"）朝堂多用俯拍全景+人物特写交替。
C. 追加示例：
```
【镜头2】：3秒 - 6秒
画面描述：近景，平视，烛光下大将军缓缓取出虎符，虎符在火光中泛着暗金色光泽，他抬眼看向对面，眉眼间神色晦暗，身后屏风虚化
音效：更漏滴答声；衣料摩擦声
台词：第4.2秒时 大将军说："兵权，可交，不可授。" 口型同步，语气：低沉有力，语速：缓慢
字幕：无
运镜：镜头缓慢向前推进，平视
镜头结束状态：虎符托在掌心，大将军目光沉静，烛火在他眼中跳动
```
D. 末尾补充规则：
1. 权谋对白保留完整逻辑与潜台词，不得删减转折句。
2. 诏书、虎符、密信等道具统一（关键）标注，特写至少1次。
3. 兵变等大场面特效控制在"火光+刀光+烟尘"级别，不过于复杂。

## 使用说明

1. 用户指定题材时按对应题材生成特化章节；未覆盖题材时参照上述结构自主编写。
2. 特化章节置于标准模板之后，标题固定为"【类型特化规则 - 适用于XX小说】"。
3. 原有内容一字不改；追加的示例紧跟标准版示例之后；末尾补充规则单独成段。
4. 特效纪律统一适用：仅在打斗、神兽出场、大功初成、法宝出现等关键动作场景加特效；常规内容不加。

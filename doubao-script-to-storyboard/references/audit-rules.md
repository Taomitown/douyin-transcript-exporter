# 审核规则库（阶段4、阶段9、阶段10、阶段11使用）

## 一、分镜词审核（阶段4：对照提示词查错误/疏忽/遗漏）

逐项核查并输出修正后的完整分镜词：

1. 顶部字段是否完整独立（编号/时长/场景/画面基础/人物/道具/全局画风/负向词），无简写无遗漏。
2. 按需触发字段（转场说明/回忆标记）顺序是否正确，未触发是否已省略。
3. 片段时长是否在1-15秒；同场景非末尾片段是否优先12-15秒。
4. 每镜头时长是否在1.5~5秒；同片段镜头时长之和是否精确等于片段时长（误差0）。
5. 含台词镜头时长是否 ≥ 台词朗读时间。
6. 台词时间点是否落在对应镜头区间内；口型同步/内心独白闭嘴标注是否正确。
7. 新场景首片段是否有转场说明、首镜头是否有渐显+转场字幕；同场景跨片段是否有"接上一片段结尾"复述。
8. 运镜字段是否含明确角度；慢动作/定格是否写入画面描述而非运镜。
9. 是否有旁白残留（必须已转为内心独白/字幕/对白）。
10. 全局风格与负向词基准是否未被修改。
11. 道具连续性、空间景深一致性是否达标（对应校验清单12、13）。
12. 台词字段纯净度是否达标（对应校验清单14）。

## 二、合规审核（阶段9：色情/暴力/恐怖/惊悚）

结合即梦 Seedance 2.0 生视频逻辑与抖音平台规则，逐镜头排查违规画面：

1. **色情**：裸露、性暗示动作、暧昧特写 → 指出并给出规避修改。
2. **暴力**：血腥伤口细节、虐杀、酷刑渲染、过度出血 → 弱化为"结果性表现"（如倒地、收手），不渲染过程细节。
3. **恐怖**：以惊吓猎奇为目的的阴森细节 → 改为氛围暗示，减少直接惊吓画面。
4. **惊悚**：持续恐惧压迫的过度渲染 → 控制惊吓强度与时长，保留张力但不渲染。
5. **其他**：血腥镜头时长、未成年人不当画面、自残虐待等。

**输出格式**：
```
【违规点N】位置：片段X 镜头Y
问题描述：<违规画面>
修改建议：<合规且不损剧情张力的改法>
```
合规判定通过后方可进入下一阶段。

## 三、即梦可生成性审核（阶段10）

结合即梦 AI Seedance 2.0 通过分镜词生视频的逻辑，排查"难以理解"与"生成难度大"的内容：

1. **抽象/歧义描述**：如"气氛微妙""情绪复杂"等 → 改为具体可见的动作、表情、光影。
2. **多角色复杂同框**：人群密集、多主体同时复杂互动 → 简化主体数量或分组分镜头。
3. **复杂特效堆叠**：多类特效+多人+复杂粒子同时出现 → 精简特效复杂度，单镜头1-2个特效元素。
4. **违反物理/几何的指令**：不可能的透视、变形、多肢体 → 改为可实现的动作。
5. **超长连续运动**：单个镜头内连续进行过多步骤 → 拆分到多个镜头或简化。
6. **文字/符号生成**：复杂文字、诗句、招牌 → 简化文字内容，标注「后期添加」由后期制作。
7. **景别/视角冲突**：同一镜头内景别与角度描述矛盾 → 统一。

**输出格式**：
```
【问题点N】位置：片段X 镜头Y
原描述：<难以理解/生成难度大的原文>
问题说明：<为何难以生成>
修改建议：<具体改写后的描述>
```
未发现问题的部分保持原样不动。

## 四、台词字段格式禁令（阶段11强制校验）

台词字段**仅允许**包含：起始时间点、角色名、台词原文、口型同步/内心独白标注、语气描述、语速描述。

**绝对禁止**：字数统计、除法计算过程、时长验算数据、语速数值（如"约3字/秒"）。

语速描述仅允许使用以下词汇：极慢、缓慢、偏慢、正常、偏快、快速、极快、渐快、渐慢、先快后慢、先慢后快。

发现违规格式必须删除后台校验信息后重新输出。

## 五、最终输出前总校验（阶段11）

对照标准模板"输出强制校验清单"15项逐条打勾；全部符合后输出"全部修改后的完整分镜词"。

# 剧本转分镜 · 即梦适配全流程 Skill

## Purpose

把用户的"剧本改分镜提示词（完整版）"及全部增强流程固化为一套**标准分镜流水线**，输出可直接交付即梦 AI（Seedance 2.0）逐片段生成的分镜词。

**标准流程：确认任务 → 输出标准模板+类型特化规则 → 等待剧本 → 生成完整分镜词 → 审核修正 → 台词检查 → 特效强化 → 景别运镜 → 时间线重排 → 合规审核 → 即梦可生成性审核 → 输出完整分镜词 → 流程固化**

## 触发与输入识别

用户提出以下任一要求即触发本 Skill：

1. "剧本转分镜""出分镜词""把剧本改成分镜"。
2. 提供剧本，要求按"剧本改分镜提示词"生成即梦分镜。
3. 要求审核、精简、加特效、加景别运镜、重排时间线、查违规、查即梦可生成性。
4. 要求"以后都按这个逻辑流程把剧本生成分镜词"（流程固化）。
5. 要求适配豆包免费生成视频（8-10秒一段、每段最多2个镜头）。

输入两要素：**剧本类型（题材）** 与 **剧本原文**。

- 题材缺失：主动询问（玄幻/武侠/都市/言情/悬疑等），不擅自假设。
- 剧本缺失：在输出"标准模板+类型特化规则"后，**等待用户发送剧本**，收到前不输出任何分镜词。

## 标准工作流（阶段化）

### 阶段0｜确认任务

1. 确认剧本类型（题材）与剧本原文是否已提供。
2. 确认输出格式：标准15秒版 / 豆包10秒版（8-10秒、每段≤2镜头）。

### 阶段1｜输出标准模板 + 类型特化规则

1. 读取 `references/standard-template.md`，**完整输出"剧本改分镜提示词（完整版）"全部内容，一字不改**。
2. 读取 `references/genre-rules.md` 对应题材，在模板末尾追加独立章节"【类型特化规则 - 适用于XX小说】"：
   - 原有内容一字不删。
   - 在标准版每个示例后额外追加该类型示例。
   - 末尾补充该类型具体创作规则。
3. 输出修改后的完整内容，无遗漏。

### 阶段2｜等待剧本

1. 明确提示"请发送剧本"。
2. **收到剧本前不输出任何分镜内容。**
3. 剧本较长时分批接收完整后再开始。

### 阶段3｜生成完整分镜词

1. 按标准模板（含类型特化规则）将剧本转化为分镜词。
2. 严格遵守硬约束：片段时长1-15秒、镜头1.5-5秒、镜头之和=片段时长、台词时长≤镜头时长、字段独立完整无简写、对白标口型/独白标闭嘴、无旁白、新场景有转场、跨片段"接上一片段结尾"、全局画风负向词不变。
3. 输出完整分镜词（每片段含顶部标注 + 各镜头标准格式）。

### 阶段4｜分镜词审核与修正

1. 读取 `references/audit-rules.md` 的"分镜词审核"部分。
2. 对照提示词要求逐项查错误、疏忽、遗漏。
3. 输出：①修改说明 ②修正后的完整分镜词。

### 阶段5｜台词问题专项检查

1. 读取 `references/refinement-rules.md` 的"台词问题专项检查"部分。
2. 按语速基准逐段核算台词能否在时间段内说完。
3. 输出：①超时台词清单（按指定格式指出）②修正后的台词安排。

### 阶段6｜特效强化

1. 读取 `references/refinement-rules.md` 的"特效规则"部分。
2. 仅在打斗、神兽出场、大功初成、法宝出现等关键动作场景添加特效；层次适度丰富、视觉震撼、不过于复杂；常规内容不加。

### 阶段7｜景别与运镜补充

1. 读取 `references/refinement-rules.md` 的"景别与运镜补充"部分。
2. 为每个镜头补充景别 + 运镜方式 + 拍摄角度；慢动作/定格写入画面描述。

### 阶段8｜时间线重排

1. 读取 `references/refinement-rules.md` 的"时间线重排"部分。
2. 特效/景别/运镜改变画面时长后，按时长要求重新安排时间线：片段时长、镜头时长、台词时间点全部重算，镜头之和=片段时长。

### 阶段9｜合规审核

1. 读取 `references/audit-rules.md` 的"合规审核"部分。
2. 结合即梦生视频逻辑与抖音规则，排查色情、暴力、恐怖、惊悚等违规画面，逐条指出并给修改建议。

### 阶段10｜即梦可生成性审核

1. 读取 `references/audit-rules.md` 的"即梦可生成性审核"部分。
2. 排查即梦难以理解、生成难度大的内容，逐条给出具体修改建议；未发现问题部分保持原样。

### 阶段11｜输出全部修改后的完整分镜词

1. 读取 `references/audit-rules.md` 的"台词字段格式禁令"与"最终输出前总校验"部分。
2. 校验台词字段纯净度（仅允许时间点/角色名/台词原文/口型或独白标注/语气/语速；禁止字数统计与验算数据；语速仅用规定词）。
3. 对照标准模板15项校验清单逐条打勾，全部通过后输出全部修改后的完整分镜词。

### 阶段12｜流程固化 + 豆包10秒适配（可选）

1. 向用户说明：后续剧本转分镜默认按阶段0-11同一流程执行。
2. 若需适配豆包免费生成视频，读取 `references/doubao-10s.md`，按"最长8-10秒一段、每段最多2个镜头、时间线规则不变、不精简、只重排"输出适配版分镜词。

## 交付契约

- 阶段1必须完整输出标准模板全部内容，一字不改；只允许其后追加类型特化章节。
- 每次"完整分镜词"输出必须可直接交付即梦生成，字段独立完整，无"同上/如前"等简写。
- 台词字段严格遵守格式禁令；输出前必须通过15项校验清单。
- 剧本文案、台词、音效、字幕、特效一律保留，不增删剧情。
- 用户中途指定"只要分镜/只要审核/只要特效"时，可只执行到对应阶段并说明停止点。

## 安全与边界

1. 分镜词严格忠于用户剧本，不新增剧情、台词、角色。
2. 涉及血腥、暴力、色情、恐怖、惊悚等描写一律按合规审核弱化处理，先整改后交付。
3. 特效复杂度以即梦可生成为准，避免过度复杂导致生成失败。
4. 不编造剧本中不存在的台词、道具、技能或设定。
5. 不向无关第三方发送用户私有稿件与个人信息。
